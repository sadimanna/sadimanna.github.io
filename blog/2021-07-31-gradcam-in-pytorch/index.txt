<p>Grad-CAM overview: Given an image and a class of interest as input, we forward propagate the image through the CNN part of the model and then through task-specific computations to obtain a raw score for the category. The gradients are set to zero for all classes except the desired class (tiger cat), which is set to 1. This signal is then backpropagated to the rectified convolutional feature maps of interest, which we combine to compute the coarse Grad-CAM localization (blue heatmap) which represents where the model has to look to make the particular decision. Finally, we pointwise multiply the heatmap with guided backpropagation to get Guided Grad-CAM visualizations which are both high-resolution and concept-specific. Source: [1]</p>
<p>In this article, we are going to learn how to plot GradCam <strong>[1]</strong> in PyTorch.</p>
<p>To get the GradCam outputs, we need the activation maps and the gradients of those activation maps.</p>
<p>Let us jump straight into the code!!</p>

<h3 id="model"><a class="heading-anchor" aria-hidden tabindex="-1" href="#model"><span class="anchor-icon">#</span></a>Model</h3>
<p>We are going to use hooks to get the <strong>activation maps</strong> and the <strong>gradients</strong> from the desired <em><strong>layer</strong></em> and <em><strong>tensor</strong></em>, respectively. For this tutorial, we are going to take the <em><strong>activation maps</strong></em>from<em><strong>layer4</strong></em>of<em><strong>ResNet50</strong></em> and <em><strong>gradients</strong></em><strong>with respect to</strong>the <em>output tensor</em> of the same.</p>
<p>We add a <em><strong>forward hook</strong></em> to the layer of the ResNet50 model. The <em><strong>forward hook</strong></em> takes as arguments, <em>the input to the layer</em> and <em>the output from the layer</em>. To the <em>output tensor</em>, we register a <em>hook</em> using the <em><strong>register_hook</strong></em> method. This method registers a <em><strong>backward hook</strong></em> to a tensor and is called every time <em>gradient</em> is computed <em>with respect to the tensor</em>. Its input argument is the <em>gradient with respect to that output tensor</em>.</p>

<pre><code class="hljs language-text">gcmodel = GradCamModel().to(‘cuda:0’)
</code></pre>
<h3 id="read-image"><a class="heading-anchor" aria-hidden tabindex="-1" href="#read-image"><span class="anchor-icon">#</span></a>Read Image</h3>
<p><img src="/images/blog/gradcam-in-pytorch/img3.jpeg" alt=""><img src="/images/blog/gradcam-in-pytorch/img4.jpeg" alt=""></p>
<p>Source: Wikipedia</p>
<blockquote>
<p>The image format and the library one uses for reading image may differ.</p>
</blockquote>
<pre><code class="hljs language-text">img = imread(‘/content/tiger.jfif’) #'bulbul.jpg'
img = resize(img, (224,224), preserve_range = True)
img = np.expand_dims(img.transpose((2,0,1)),0)
img /= 255.0
mean = np.array([0.485, 0.456, 0.406]).reshape((1,3,1,1))
std = np.array([0.229, 0.224, 0.225]).reshape((1,3,1,1))
img = (img — mean)/std
inpimg = torch.from_numpy(img).to(‘cuda:0’, torch.float32)
</code></pre>
<h3 id="compute-gradient-class-activation-maps"><a class="heading-anchor" aria-hidden tabindex="-1" href="#compute-gradient-class-activation-maps"><span class="anchor-icon">#</span></a>Compute Gradient Class Activation Maps</h3>
<pre><code class="hljs language-text">out, acts = gcmodel(inpimg)
</code></pre>
<pre><code class="hljs language-text">acts = acts.detach().cpu()
</code></pre>
<pre><code class="hljs language-text">loss = nn.CrossEntropyLoss()(out,torch.from_numpy(np.array([600])).to(‘cuda:0’))
loss.backward()

grads = gcmodel.get_act_grads().detach().cpu()

pooled_grads = torch.mean(grads, dim=[0,2,3]).detach().cpu()

for i in range(acts.shape[1]):
    acts[:,i,:,:] *= pooled_grads[i]
</code></pre>
<pre><code class="hljs language-text">heatmap_j = torch.mean(acts, dim = 1).squeeze()
</code></pre>
<pre><code class="hljs language-text">heatmap_j_max = heatmap_j.max(axis = 0)[0]
</code></pre>
<pre><code class="hljs language-text">heatmap_j /= heatmap_j_max
</code></pre>
<p>Now, the heatmap needs to be resized and colour mapped.</p>
<h3 id="resize-heatmap"><a class="heading-anchor" aria-hidden tabindex="-1" href="#resize-heatmap"><span class="anchor-icon">#</span></a>Resize Heatmap</h3>
<pre><code class="hljs language-text">heatmap_j = resize(heatmap_j,(224,224),preserve_range=True)
</code></pre>
<h3 id="colour-mapping"><a class="heading-anchor" aria-hidden tabindex="-1" href="#colour-mapping"><span class="anchor-icon">#</span></a>Colour Mapping</h3>
<pre><code class="hljs language-text">cmap = mpl.cm.get_cmap(‘jet’,256)
heatmap_j2 = cmap(heatmap_j,alpha = 0.2)
</code></pre>
<h3 id="plotting"><a class="heading-anchor" aria-hidden tabindex="-1" href="#plotting"><span class="anchor-icon">#</span></a>Plotting</h3>
<pre><code class="hljs language-text">fig, axs = plt.subplots(1,1,figsize = (5,5))
axs.imshow((img*std+mean)[0].transpose(1,2,0))
axs.imshow(heatmap_j2)
plt.show()
</code></pre>
