<h3 id="what-is-integer-partitioning-problem"><a class="heading-anchor" aria-hidden tabindex="-1" href="#what-is-integer-partitioning-problem"><span class="anchor-icon">#</span></a>What is Integer Partitioning Problem?</h3>
<p>In <strong>Number Theory</strong> and <strong>Combinatorics</strong>, the partition of a positive integer <em><strong>N</strong></em> into a multiset of positive integers, such that the elements sum to N. The number of partitions of the positive integer <em><strong>N</strong></em> is denoted by <em><strong>pₙ</strong></em>.</p>
<blockquote>
<p>The partitions of 5 are :</p>
</blockquote>
<blockquote>
<p>5</p>
</blockquote>
<blockquote>
<p>3 + 2</p>
</blockquote>
<blockquote>
<p>4 + 1</p>
</blockquote>
<blockquote>
<p>3 + 1 + 1</p>
</blockquote>
<blockquote>
<p>2 + 2 + 1</p>
</blockquote>
<blockquote>
<p>2 + 1 + 1 + 1</p>
</blockquote>
<blockquote>
<p>1 + 1 + 1 + 1 + 1</p>
</blockquote>
<blockquote>
<p>Thus <em><strong>p₅</strong></em> = 7</p>
</blockquote>
<p>The number of partitions can be found using Generating Functions <strong>GF</strong>(<em><strong>x</strong></em>). In fact, the total number of partitions <em><strong>pₙ</strong></em> is equal to the co-efficient of <em><strong>xⁿ</strong></em> in <strong>GF</strong>(<em><strong>x</strong></em>)</p>
<p>The number of times a certain part is included in a partition formation is reflected in the generating function. Thus for any number of repetitions of any part <em><strong>k</strong></em> the generating function for <em><strong>k</strong></em> becomes</p>
<p><img src="/images/blog/solving-integer-partitioning-problem-using-python/img2.png" alt=""></p>
<p>For all such parts, we multiply the individual generating functions, to get</p>
<p><img src="/images/blog/solving-integer-partitioning-problem-using-python/img3.png" alt=""></p>
<p>The above one is an infinite product. If we want a particular coefficent <em><strong>pₙ</strong></em> we need only multiply out these factors involving <em><strong>x</strong></em> to a power <em><strong>n</strong></em> or less and are only finitely many of these terms.</p>
<p>To get a finite product, we can calculate the generating function by multiplying polynomials which are finite geometric series. The factor for each part <em><strong>k</strong></em> is expressed as</p>
<p><img src="/images/blog/solving-integer-partitioning-problem-using-python/img4.png" alt=""></p>
<blockquote>
<p>For example, in the partition of the integer <em><strong>5</strong></em>, the factor corresponding to <em><strong>1</strong></em> is</p>
</blockquote>
<p><img src="/images/blog/solving-integer-partitioning-problem-using-python/img5.png" alt=""></p>
<blockquote>
<p>We know that 5 can be partitioned into two 2s and one 1. And it is quite evident that 5 cannot contain more than two 2s. Thus, the highest power of <em><strong>x²</strong></em> in the factor for 2 need not contain terms greater than (<em><strong>x²</strong></em>)<em><strong>²</strong></em>. The factor corresponding to 2 will be <em><strong>1</strong></em> <em><strong>+</strong></em> <em><strong>x²</strong></em> <em><strong>+</strong></em> <em><strong>x⁴</strong></em>.</p>
</blockquote>
<blockquote>
<p>If we revisit the above argument, we can also say that 5 cannot contain three or more than three 2s. This statement is same as discarding the terms which account for three or more than three 2s from the factor which accounts for “any number of repetitions of 2” . Thus the above statemet can be expressed as</p>
</blockquote>
<p><img src="/images/blog/solving-integer-partitioning-problem-using-python/img6.png" alt=""></p>
<p>Thus, the Generating Function can be expressed as</p>
<p><img src="/images/blog/solving-integer-partitioning-problem-using-python/img7.png" alt=""></p>
<blockquote>
<p>Find the number of ways 8 can be partitioned into integers</p>
</blockquote>
<ol>
<li>8 can contain exactly eight 1s</li>
<li>8 can contain exactly four 2s</li>
<li>8 can contain maximum two 3s</li>
<li>8 can contain exactly two 4s</li>
<li>8 can contain maximum one 5</li>
<li>8 can contain maximum one 6</li>
<li>8 can contain maximum one 7</li>
<li>8 can contain exactly one 8</li>
</ol>
<p>Thus, the Generating Function can be expressed as</p>
<p><img src="/images/blog/solving-integer-partitioning-problem-using-python/img8.png" alt=""></p>
<p>The co-efficient of <em><strong>x⁸</strong></em> in the above expression is the number of ways 8 can be partitioned into integers, that is <em><strong>pₙ</strong></em> = 22</p>

<h4 id="how-many-different-ways-rs-200-can-be-made-using-denominations-of-rs-1-rs-2-rs-5-rs-10-rs-20-rs-50-rs-100-and-rs200"><a class="heading-anchor" aria-hidden tabindex="-1" href="#how-many-different-ways-rs-200-can-be-made-using-denominations-of-rs-1-rs-2-rs-5-rs-10-rs-20-rs-50-rs-100-and-rs200"><span class="anchor-icon">#</span></a>How many different ways Rs. 200 can be made using denominations of Rs. 1, Rs. 2, Rs. 5, Rs. 10, Rs. 20, Rs. 50, Rs. 100 and Rs. 200?</h4>
<p>This problem is the same as the above problems. Here, we have to partition 200 into some specific integers. So, we have to consider the factors of only those integers in the Generating function.</p>
<p>The factor for <em><strong>Rs. 1</strong></em> is (<em><strong>1+ x + x²</strong></em> <em><strong>+</strong></em> <em><strong>x³</strong></em> <em><strong>+</strong></em> … <em><strong>+</strong></em> <em><strong>x¹⁹⁹</strong></em> <em><strong>+</strong></em> <em><strong>x²⁰⁰</strong></em>)</p>
<p>The factor for <em><strong>Rs. 2</strong></em> is (<em><strong>1+ x² + x⁴ + x⁶ + … + x¹⁹⁸ + x²⁰⁰</strong></em>)</p>
<p>The factor for <em><strong>Rs. 5</strong></em> is (<em><strong>1 + x⁵ + x¹⁰ + x¹⁵ + … + x¹⁹⁵ + x²⁰⁰</strong></em>)</p>
<p>The factor for <em><strong>Rs. 10</strong></em> is (<em><strong>1 + x¹⁰ + x²⁰ + x³⁰ + … + x¹⁹⁰ + x²⁰⁰</strong></em>)</p>
<p>The factor for <em><strong>Rs. 20</strong></em> is (<em><strong>1 + x²⁰ + x⁴⁰ + x⁶⁰ + … + x¹⁸⁰ + x²⁰⁰</strong></em>)</p>
<p>The factor for <em><strong>Rs. 50</strong></em> is (<em><strong>1 + x⁵⁰ + x¹⁰⁰ + x¹⁵⁰ + x²⁰⁰</strong></em>)</p>
<p>The factor for <em><strong>Rs. 100</strong></em> is (<em><strong>1 + x¹⁰⁰ + x²⁰⁰</strong></em>)</p>
<p>The factor for <em><strong>Rs. 200</strong></em> is (<em><strong>1 + x²⁰⁰</strong></em>)</p>
<p>The generating function is the product of all the above factors</p>
<p>(<em><strong>1 + x + x² +…+x²⁰⁰</strong></em>) (<em><strong>1 + x² + x⁴ +…+x²⁰⁰</strong></em>)(<em><strong>1+x⁵+x¹⁰+…+x²⁰⁰</strong></em>)(<em><strong>1+x¹⁰+x²⁰+…+x²⁰⁰</strong></em>)(<em><strong>1+x²⁰+x⁴⁰+…+x²⁰⁰</strong></em>)(<em><strong>1+x⁵⁰+..+x²⁰⁰</strong></em>)(<em><strong>1+x¹⁰⁰+x²⁰⁰</strong></em>)(<em><strong>1+x²⁰⁰</strong></em>)</p>
<p>The number of ways <em><strong>Rs. 200</strong></em> can be partitioned with the given denominations is <strong>73682</strong>, that is <em><strong>p₂₀₀</strong></em> = <strong>73682</strong></p>
