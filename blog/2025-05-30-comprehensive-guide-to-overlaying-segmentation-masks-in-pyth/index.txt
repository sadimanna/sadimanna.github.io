<p><img src="/images/blog/comprehensive-guide-to-overlaying-segmentation-masks-in-pyth/img1.jpeg" alt=""></p>
<p>Segmentation masks are fundamental in computer vision applications, from medical imaging to autonomous vehicles. Visualising these masks effectively helps in model evaluation and debugging. In this guide, we’ll explore two powerful methods for overlaying segmentation masks on images:</p>
<ol>
<li><strong>Transparent Overlay</strong> (using alpha blending with <em><code>cv2.addWeighted</code></em>)</li>
<li><strong>Solid Overlay</strong> (direct pixel replacement)</li>
</ol>
<p>We’ll implement both methods using OpenCV and NumPy, with detailed explanations and complete code examples.</p>
<h3 id="understanding-themethods"><a class="heading-anchor" aria-hidden tabindex="-1" href="#understanding-themethods"><span class="anchor-icon">#</span></a>Understanding the Methods</h3>
<h3 id="1-transparent-overlay-alpha-blending"><a class="heading-anchor" aria-hidden tabindex="-1" href="#1-transparent-overlay-alpha-blending"><span class="anchor-icon">#</span></a>1. Transparent Overlay (Alpha Blending)</h3>
<p>Alpha blending creates a semi-transparent overlay that allows the original image to show through the mask. This is particularly useful when you want to maintain context while visualising the segmentation.</p>
<p>Key Characteristics:</p>
<ul>
<li>Adjustable transparency (alpha value between 0 and 1)</li>
<li>Smooth blending between the mask and the original image</li>
<li>Ideal for qualitative analysis where context matters</li>
</ul>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> cv2 
<span class="hljs-keyword">import</span> numpy <span class="hljs-keyword">as</span> np 
<span class="hljs-keyword">import</span> os  

<span class="hljs-keyword">def</span> <span class="hljs-title function_">transparent_overlay</span>(<span class="hljs-params">original_img, mask, color=(<span class="hljs-params"><span class="hljs-number">0</span>, <span class="hljs-number">255</span>, <span class="hljs-number">0</span></span>), alpha=<span class="hljs-number">0.3</span></span>):
    <span class="hljs-string">"""     
    Create a transparent overlay of a segmentation mask on an image.
          Args:         
          original_img: Input image in BGR format         
          mask: Binary mask (0 or 255)         
          color: BGR tuple for mask color (default: green)         
          alpha: Transparency level (0-1)          
    Returns:         
          Image with transparent overlay     
    """</span>     
    <span class="hljs-comment"># Ensure mask is binary and 3-channel     </span>
    <span class="hljs-keyword">if</span> <span class="hljs-built_in">len</span>(mask.shape) == <span class="hljs-number">2</span>:
        mask = (mask > <span class="hljs-number">0</span>).astype(np.uint8) * <span class="hljs-number">255</span>        
        mask = cv2.cvtColor(mask, cv2.COLOR_GRAY2BGR)          
    <span class="hljs-comment"># Apply color to mask</span>
    colored_mask = cv2.bitwise_and(mask, color) 
    <span class="hljs-comment"># Blend with original image     </span>
    <span class="hljs-keyword">return</span> cv2.addWeighted(original_img, <span class="hljs-number">1</span> - alpha, colored_mask, alpha, <span class="hljs-number">0</span>)
</code></pre>
<h3 id="2-solid-overlay-pixel-replacement"><a class="heading-anchor" aria-hidden tabindex="-1" href="#2-solid-overlay-pixel-replacement"><span class="anchor-icon">#</span></a>2. Solid Overlay (Pixel Replacement)</h3>
<p>This method completely replaces pixels in the mask region with a solid colour, providing high-contrast visualisation of the segmented areas.</p>
<p>Key Characteristics:</p>
<ul>
<li>No transparency — mask areas are fully colored</li>
<li>Clear, unambiguous visualisation of segmentation boundaries</li>
<li>Best for binary segmentation tasks where precision is crucial</li>
</ul>
<pre><code class="hljs language-python"><span class="hljs-keyword">def</span> <span class="hljs-title function_">solid_overlay</span>(<span class="hljs-params">original_img, mask, color=(<span class="hljs-params"><span class="hljs-number">0</span>, <span class="hljs-number">0</span>, <span class="hljs-number">255</span></span>)</span>):
     <span class="hljs-string">"""     
      Create a solid color overlay of a segmentation mask on an image.
          Args:         
          original_img: Input image in BGR format         
          mask: Binary mask (0 or 255)         
          color: BGR tuple for mask color (default: red)          
      Returns:         
          Image with solid overlay     
      """</span>     
      <span class="hljs-comment"># Convert mask to 3-channel if needed     </span>
      <span class="hljs-keyword">if</span> <span class="hljs-built_in">len</span>(mask.shape) == <span class="hljs-number">2</span>:
          mask = (mask > <span class="hljs-number">0</span>).astype(np.uint8) 
          mask_3d = np.repeat(mask[:, :, np.newaxis], <span class="hljs-number">3</span>, axis=<span class="hljs-number">2</span>) 
      <span class="hljs-keyword">else</span>: 
          mask_3d = (mask > <span class="hljs-number">0</span>).astype(np.uint8)  
        
      <span class="hljs-comment"># Apply color where mask is active     </span>
      <span class="hljs-keyword">return</span> np.where(mask_3d > <span class="hljs-number">0</span>, color, original_img)
</code></pre>

<h3 id="prerequisites"><a class="heading-anchor" aria-hidden tabindex="-1" href="#prerequisites"><span class="anchor-icon">#</span></a>Prerequisites</h3>

<ul>
<li>Python 3.x</li>
<li>OpenCV (<em><code>pip install opencv-python</code></em>)</li>
<li>NumPy (<em><code>pip install numpy</code></em>)</li>
</ul>
<h3 id="complete-code-implementation"><a class="heading-anchor" aria-hidden tabindex="-1" href="#complete-code-implementation"><span class="anchor-icon">#</span></a>Complete Code Implementation</h3>
<pre><code class="hljs language-python"><span class="hljs-keyword">def</span> <span class="hljs-title function_">compare_masks</span>(<span class="hljs-params">original_img, pred_mask, gt_mask, output_dir</span>):
    <span class="hljs-string">"""     
    Compare predicted and ground truth masks using both overlay methods.
          Args:         
          original_img: Base image         
          pred_mask: Predicted segmentation mask         
          gt_mask: Ground truth mask         
          output_dir: Directory to save results     
    """</span>     
    os.makedirs(output_dir, exist_ok=<span class="hljs-literal">True</span>)          
    <span class="hljs-comment"># Transparent overlays     </span>
    pred_trans = transparent_overlay(original_img, pred_mask, (<span class="hljs-number">0</span>, <span class="hljs-number">0</span>, <span class="hljs-number">255</span>))     
    gt_trans = transparent_overlay(original_img, gt_mask, (<span class="hljs-number">0</span>, <span class="hljs-number">255</span>, <span class="hljs-number">0</span>))          
    <span class="hljs-comment"># Solid overlays     </span>
    pred_solid = solid_overlay(original_img, pred_mask, (<span class="hljs-number">0</span>, <span class="hljs-number">0</span>, <span class="hljs-number">255</span>))     
    gt_solid = solid_overlay(original_img, gt_mask, (<span class="hljs-number">0</span>, <span class="hljs-number">255</span>, <span class="hljs-number">0</span>))          
    <span class="hljs-comment"># Overlap visualization     </span>
    overlap = cv2.bitwise_and((pred_mask > <span class="hljs-number">0</span>).astype(np.uint8),
                              (gt_mask > <span class="hljs-number">0</span>).astype(np.uint8)) * <span class="hljs-number">255</span>     
    overlap_solid = solid_overlay(original_img, overlap, (<span class="hljs-number">0</span>, <span class="hljs-number">255</span>, <span class="hljs-number">255</span>))          

    <span class="hljs-comment"># Save results     </span>
    cv2.imwrite(<span class="hljs-string">f"<span class="hljs-subst">{output_dir}</span>/predicted_transparent.png"</span>, pred_trans)     
    cv2.imwrite(<span class="hljs-string">f"<span class="hljs-subst">{output_dir}</span>/ground_truth_transparent.png"</span>, gt_trans)     
    cv2.imwrite(<span class="hljs-string">f"<span class="hljs-subst">{output_dir}</span>/predicted_solid.png"</span>, pred_solid)     
    cv2.imwrite(<span class="hljs-string">f"<span class="hljs-subst">{output_dir}</span>/ground_truth_solid.png"</span>, gt_solid)     
    cv2.imwrite(<span class="hljs-string">f"<span class="hljs-subst">{output_dir}</span>/overlap_solid.png"</span>, overlap_solid)  

<span class="hljs-comment"># Example usage </span>

<span class="hljs-keyword">if</span> __name__ == <span class="hljs-string">"__main__"</span>:     
    <span class="hljs-comment"># Load sample images     </span>
    original = cv2.imread(<span class="hljs-string">"sample_image.jpg"</span>)     
    pred_mask = cv2.imread(<span class="hljs-string">"predicted_mask.png"</span>, cv2.IMREAD_GRAYSCALE)     
    gt_mask = cv2.imread(<span class="hljs-string">"ground_truth_mask.png"</span>, cv2.IMREAD_GRAYSCALE)          
    <span class="hljs-comment"># Process and save results     </span>
    compare_masks(original, pred_mask, gt_mask, <span class="hljs-string">"output_results"</span>)          
    <span class="hljs-built_in">print</span>(<span class="hljs-string">"Processing complete. Results saved to 'output_results' folder."</span>)
</code></pre>
<h3 id="practical-applications"><a class="heading-anchor" aria-hidden tabindex="-1" href="#practical-applications"><span class="anchor-icon">#</span></a>Practical Applications</h3>
<h3 id="medical-imaging"><a class="heading-anchor" aria-hidden tabindex="-1" href="#medical-imaging"><span class="anchor-icon">#</span></a>Medical Imaging</h3>
<p>In radiology, transparent overlays help doctors see tumours (marked in red) while maintaining visibility of surrounding anatomy. The adjustable alpha allows balancing between mask visibility and anatomical context.</p>
<h3 id="autonomous-vehicles"><a class="heading-anchor" aria-hidden tabindex="-1" href="#autonomous-vehicles"><span class="anchor-icon">#</span></a>Autonomous Vehicles</h3>
<p>For self-driving car systems, solid overlays clearly show detected pedestrians (red) and vehicles (blue) against the camera feed, ensuring quick visual verification of detection accuracy.</p>
<h3 id="quality-control"><a class="heading-anchor" aria-hidden tabindex="-1" href="#quality-control"><span class="anchor-icon">#</span></a>Quality Control</h3>
<p>In industrial inspection, solid overlays highlight defective regions on products, allowing quality control personnel to identify issues at a glance.</p>
<h3 id="tips-for-effective-visualisation"><a class="heading-anchor" aria-hidden tabindex="-1" href="#tips-for-effective-visualisation"><span class="anchor-icon">#</span></a>Tips for Effective Visualisation</h3>
<ol>
<li>Colour Selection:</li>
</ol>
<ul>
<li>Use high-visibility colours (red, green, blue)</li>
<li>Maintain consistency across your team/project</li>
<li>Consider colourblind-friendly palettes</li>
</ul>
<ol start="2">
<li>Transparency Adjustment:</li>
</ol>
<ul>
<li>Start with alpha=0.3 and adjust based on needs</li>
<li>Use a lower alpha for dense masks</li>
<li>Use a higher alpha for sparse masks</li>
</ul>
<ol start="3">
<li>Performance Considerations:</li>
</ol>
<ul>
<li>For video processing, solid overlays are faster</li>
<li>Transparent overlays work well for static image analysis</li>
</ul>
<h3 id="troubleshooting-commonissues"><a class="heading-anchor" aria-hidden tabindex="-1" href="#troubleshooting-commonissues"><span class="anchor-icon">#</span></a>Troubleshooting Common Issues</h3>
<p>Problem: Masks don’t align with the image</p>
<ul>
<li>Solution: Verify both image and mask have the same dimensions and coordinate system</li>
</ul>
<p>Problem: Colours appear incorrect</p>
<ul>
<li>Solution: Remember OpenCV uses BGR order, not RGB</li>
</ul>
<p>Problem: Overlay looks pixelated</p>
<ul>
<li>Solution: Ensure masks are binary (0 or 255) before processing</li>
</ul>

<li>Solid overlays for clear, unambiguous visualisation</li>
</ul>
