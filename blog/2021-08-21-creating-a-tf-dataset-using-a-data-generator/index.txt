<p>In this article, we are going to build a <em><strong>tf.data.Dataset</strong></em> from a <strong>data generator</strong>. This data generator will perform <em>data fetching</em>, <em>pre-processing</em>, <em>augmentations</em> within itself.</p>
<p>We will be using the <em><strong>array</strong></em> dataset for this article, that is, the data and labels are stored in an array. If the dataset can’t be stored in an array, we can create a DataFrame from the filenames and use it in place of the data array. By changing some methods, this generator can be adapted to any dataset.</p>
<p>One important feature of the generator is that it should be callable. For this, we need the method <em><strong>__call__.</strong></em></p>
<p>Let us look at a sample code for creating such a Generator</p>
<h4 id="instantiate-a-generator"><a class="heading-anchor" aria-hidden tabindex="-1" href="#instantiate-a-generator"><span class="anchor-icon">#</span></a>Instantiate a Generator</h4>
<pre><code class="hljs language-text">dg = ArrayDataset(‘train’, tr_x, tr_y, mean, std, transforms)
</code></pre>
<p><strong>mean</strong> and <strong>std</strong> will depend on the dataset and <strong>transforms</strong> is a function passed to augment the data.</p>
<h4 id="instantiate-adataset"><a class="heading-anchor" aria-hidden tabindex="-1" href="#instantiate-adataset"><span class="anchor-icon">#</span></a>Instantiate a Dataset</h4>
<pre><code class="hljs language-text">ot = (tf.float32, tf.int64)
os = (tf.TensorShape([tr_x.shape[1:]), tf.TensorShape([]))
ds = tf.data.Dataset.from_generator(dg, 
                                    output_types = ot, 
                                    output_shapes = os)
ds = ds.batch(BATCH_SIZE)
</code></pre>
<p>To use this Dataset in training, we can just iterate over it like</p>
<pre><code class="hljs language-text">for batch in ds:
    x,y = batch
    # Training step
</code></pre>
