<h2 id="running-shell-scripts-on-windows"><a class="heading-anchor" aria-hidden tabindex="-1" href="#running-shell-scripts-on-windows"><span class="anchor-icon">#</span></a>Running Shell Scripts on Windows</h2>

<p>YES, we can. But that will require a bit of work.</p>

<h3 id="1-using-bash-on-windows-git-bash-cygwin-mingw"><a class="heading-anchor" aria-hidden tabindex="-1" href="#1-using-bash-on-windows-git-bash-cygwin-mingw"><span class="anchor-icon">#</span></a>1. Using Bash on Windows (Git Bash, Cygwin, MinGW)</h3>
<p>Installing Cygwin, MinGW, or Git Bash on Windows and adding the path where it is installed to the Environment variables will allow us to run “.sh” files on Windows from Command Prompt.</p>
<h3 id="2-converting-sh-files-to-bat-batch-scripts"><a class="heading-anchor" aria-hidden tabindex="-1" href="#2-converting-sh-files-to-bat-batch-scripts"><span class="anchor-icon">#</span></a>2. Converting .sh Files to .bat Batch Scripts</h3>
<p>“<em><strong>.bat</strong></em>” extensions are used for batch scripts, which are also used to automate tasks on Windows. Commands for Shell scripting and Batch scripting are not exactly the same, but commands from shell scripts can be converted for like-to-like commands in batch scripts.</p>
<p>A simple converter can be found here: <a href="https://daniel-sc.github.io/bash-shell-to-bat-converter/">https://daniel-sc.github.io/bash-shell-to-bat-converter/</a></p>
<p>However, this tool does not support converting loop conversion from shell to batch. Any user can do so by studying the tutorials given below:</p>
