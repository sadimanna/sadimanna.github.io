<p>Suppose, we have data distributed according to the probability distribution function <strong>P(<em>x</em>).</strong> An element <em><strong>x</strong></em> appears randomly and independently according to the distribution <strong>P(<em>x</em>).</strong></p>
<p>Again, suppose you are the <em>supervisor.</em> You classify and label each such element <em><strong>x</strong></em> into <em><strong>k</strong></em> classes. We denote the distribution according to which the supervisor, that is, you carry out the classification, using <strong>P(<em>ω</em>|<em>x</em>),</strong> where <strong>ω</strong> ∈ {<strong>0</strong>, <strong>1</strong>,..,<strong>k-1</strong>}.</p>
<h2 id="pattern-recognition-problem-formulation"><a class="heading-anchor" aria-hidden tabindex="-1" href="#pattern-recognition-problem-formulation"><span class="anchor-icon">#</span></a>Pattern Recognition Problem Formulation</h2>
<p>In a Pattern Recognition problem, neither the data distribution <strong>P(<em>x</em>)</strong>, nor the conditional probability distribution <strong>P(ω|<em>x</em>)</strong> is known. But, we do have the empirical data <em><strong>x</strong></em> and if <strong>P(<em>x</em>)</strong> and <strong>P(ω|<em>x</em>)</strong> exist, then <strong>P(ω, <em>x</em>) = P(ω|<em>x</em>).P(<em>x</em>)</strong> alsoexists.</p>
<h2 id="the-risk-functional"><a class="heading-anchor" aria-hidden tabindex="-1" href="#the-risk-functional"><span class="anchor-icon">#</span></a>The Risk Functional</h2>
<p>From the <a href="https://medium.com/the-owl/statistical-learning-theory-part-3-e313539fe13c">previous article</a> in this series</p>
<p><a href="https://medium.com/the-owl/statistical-learning-theory-part-3-e313539fe13c" title="https://medium.com/the-owl/statistical-learning-theory-part-3-e313539fe13c"><strong>Statistical Learning Theory Part 3</strong><br>
<em>Approaches to the Learning Problem Part 1</em>medium.com</a></p>
<p>we can learn that in the problem of risk minimization from empirical data, the objective is to select a function <strong>g*(<em>z</em>)</strong> based on a criterion,from a set of functions {<strong>g</strong>(<em><strong>z</strong></em>)}such that the <strong>RISK</strong></p>
<blockquote>
<p><strong>R(g(<em>z</em>)) = ∫ L(<em>z</em>,g(<em>z</em>)) dF(<em>z</em>)</strong></p>
</blockquote>
<p>is minimized (where <strong>F(<em>z</em>)</strong> is the probability distribution function on <em><strong>Z</strong></em> ).</p>
<p>Reformulating the risk functional in the parametric form, we get</p>
<blockquote>
<p><strong>R(<em>α</em>) = ∫ Q(<em>z</em>,<em>α</em>) dF(<em>z</em>), α ∈ Λ</strong></p>
</blockquote>
<p>where,</p>
<blockquote>
<p>Q(z,α) = L(z,g(z,α))</p>
</blockquote>
<p>is called the <strong>Loss function.</strong></p>
<hr>
<p>Now, for the pattern recognition problems, the set of functions <strong>g(<em>x</em>,α)</strong> will be such that they take only values from the set <strong>{0, 1, …, k-1}.</strong> Also, note that the empirical data consisting of a random independent sample of pairs</p>
<p><img src="/images/blog/statistical-learning-theory-part-4/img2.png" alt=""></p>
<p>is given.</p>
<h2 id="simplest-loss-function-for-classification"><a class="heading-anchor" aria-hidden tabindex="-1" href="#simplest-loss-function-for-classification"><span class="anchor-icon">#</span></a>Simplest Loss Function for Classification</h2>
<p>Consider the simplest loss function</p>
<p><img src="/images/blog/statistical-learning-theory-part-4/img3.png" alt=""></p>
<p>where, <strong>L</strong>(<em><strong>ω</strong></em>,<strong>g</strong>(<em><strong>x</strong></em>,<em><strong>α</strong></em>)) = 1 if <em><strong>ω</strong></em> ≠ <strong>g</strong> and 0 otherwise. This loss function does not contribute to the total risk if the decision given by the function <strong>g</strong>(<em><strong>x</strong></em>,<em><strong>α</strong></em>) is correct but adds 1 for every incorrect decision made.</p>
<p>The problem of pattern recognition is to minimize the risk functional</p>
<blockquote>
<p>R(α) = ∫ L(ω, g(x,α)) dF(ω, x)</p>
</blockquote>
<p>over the set of functions <strong>g</strong>(<em><strong>x</strong></em>,<strong>α</strong>), <strong>α</strong> ∈ <strong>Λ</strong> and the given empirical data.</p>
<p>The above expression for the risk functional actually denotes the probability of classification error for any decision rule <strong>g</strong>(<em><strong>x</strong></em>,<em><strong>α</strong></em>).</p>
<h3 id="derivation-and-joint-distribution"><a class="heading-anchor" aria-hidden tabindex="-1" href="#derivation-and-joint-distribution"><span class="anchor-icon">#</span></a>Derivation and Joint Distribution</h3>
<p>Since, <strong>F</strong>(<em><strong>ω</strong></em>,<em><strong>x</strong></em>) is the cumulative joint distribution function</p>
<p><img src="/images/blog/statistical-learning-theory-part-4/img4.png" alt=""></p>
<p>since ω takes only discrete values from the set {0, 1, .., k-1}.</p>
<p>So, we can write <strong>dF</strong>(<em><strong>ω</strong></em>,<em><strong>x</strong></em>) as</p>
<p><img src="/images/blog/statistical-learning-theory-part-4/img5.png" alt=""></p>
<p>Thus, the risk functional <strong>R</strong>(<strong>α</strong>) can be written as</p>
<p><img src="/images/blog/statistical-learning-theory-part-4/img6.png" alt=""></p>
<p>For a chosen <em><strong>α</strong></em>, <strong>g</strong>(<em><strong>x</strong></em>,<em><strong>α</strong></em>) gives the decisions on the random independent samples of empirical data. If all the decisions of the function <strong>g</strong>(<em><strong>x</strong></em>,<em><strong>α</strong></em>) are wrong, the risk functional value becomes equal to <strong>F</strong>(<em><strong>k-1</strong></em>,<strong>∞</strong>), i.e. <strong>1</strong>. Otherwise, we can say that <strong>R</strong>(<em><strong>α</strong></em>) ≤ <strong>1</strong>. This follows the rule of probability.</p>
<hr>
<p>For a binary classification problem and for a single sample <em><strong>x</strong></em> (let’s say this is a positive sample, i.e. <em><strong>ω</strong></em> = <strong>1</strong>), if the sample is misclassified then,</p>
<blockquote>
<p><strong>R</strong>(<em><strong>α</strong></em>) = <strong>L</strong>(<strong>1</strong>, <strong>g</strong>(<em><strong>x</strong></em>,<em><strong>α</strong></em>)). <em><strong>f</strong></em>(1,x) + <strong>L</strong>(<strong>0</strong>, <strong>g</strong>(<em><strong>x</strong></em>,<em><strong>α</strong></em>)). <em><strong>f</strong></em>(0,x) = <em><strong>f</strong></em>(1***,x***) = 1</p>
</blockquote>
<p>Had the decision rule correctly classified the sample <em><strong>x</strong></em>, then</p>
<blockquote>
<p>R(α) = L(1, g(x,α)). f(1,x) + L(0, g(x,α)). f(0,x) = f(0,x) = 0</p>
</blockquote>
<hr>
<p>However, the joint distribution are not this simple in real-life data and often have multivariate properties. The discrete values will be replaced by probability values in the above equations.</p>
<hr>
<p>The problem of pattern recognition can thus be reduced to a problem of risk minimization based on the empirical data even though the Cumulative Joint Distribution Function <strong>F</strong>(<em><strong>ω</strong></em>,<em><strong>x</strong></em>) is unknown.</p>
<hr>
<h2 id="restrictions-on-loss-functions"><a class="heading-anchor" aria-hidden tabindex="-1" href="#restrictions-on-loss-functions"><span class="anchor-icon">#</span></a>Restrictions on Loss Functions</h2>
<p>The set of loss functions <strong>Q</strong>(<strong>z</strong>,<strong>α</strong>) is not arbitrary and follows the following restrictions:</p>
<ol>
<li>The vector <em><strong>z</strong></em> consists of <strong>n+1</strong> coordinates: coordinate <strong>ω,</strong> which takes on only a finite number of values and <strong>n</strong> coordinates which form the <strong>n</strong>-dimensional vector <strong><em>x.<br>
z</em> = [ω , <em>x</em>]</strong></li>
<li>The set of functions <strong>Q</strong>(<strong>z</strong>,<strong>α</strong>), <strong>α</strong> ∈ <strong>Λ</strong>, is given by <strong>L</strong>(<em><strong>ω</strong></em>, <strong>g</strong>(<em><strong>z</strong></em>,<em><strong>α</strong></em>)) and takes only finite values.</li>
</ol>
<p>This specific feature of the risk minimization problem characterizes the pattern recognition problem.</p>
