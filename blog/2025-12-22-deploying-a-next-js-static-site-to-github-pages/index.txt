<h3 id="prerequisites"><a class="heading-anchor" aria-hidden tabindex="-1" href="#prerequisites"><span class="anchor-icon">#</span></a>Prerequisites</h3>
<ol>
<li>
<p><strong>Node.js</strong> and <em><strong>npm</strong></em> are installed</p>
</li>
<li>
<p>A <strong>Next.js</strong> project</p>
</li>
</ol>
<blockquote>
<p>Create one with</p>
</blockquote>
<pre><code class="hljs language-text">npx create-next-app my-app
</code></pre>
<ol start="3">
<li>A <strong>GitHub</strong> repository for your project</li>
</ol>
<h3 id="prepare-your-nextjs-app-for-staticexport"><a class="heading-anchor" aria-hidden tabindex="-1" href="#prepare-your-nextjs-app-for-staticexport"><span class="anchor-icon">#</span></a>Prepare Your Next.js App for Static Export</h3>
<h4 id="1-ensure-your-pages-arestatic"><a class="heading-anchor" aria-hidden tabindex="-1" href="#1-ensure-your-pages-arestatic"><span class="anchor-icon">#</span></a><strong>1. Ensure Your Pages Are Static</strong></h4>
<p>Only use <code>getStaticProps</code> and <code>getStaticPaths</code> or no data fetching at all.</p>
<p>Do NOT use <code>getServerSideProps</code> or API routes — they are not supported for static export.</p>
<h4 id="2-configure-nextconfigjs"><a class="heading-anchor" aria-hidden tabindex="-1" href="#2-configure-nextconfigjs"><span class="anchor-icon">#</span></a>2. Configure <code>next.config.js</code></h4>
<p>Add or update your <code>next.config.js</code> to enable static export and set up the path for GitHub Pages:</p>
<pre><code class="hljs language-text">/ @type {import(‘next’).NextConfig} */
const repoName = ‘your-repo-name’; // Replace with your repo name
const nextConfig = {
 output: ‘export’,
 // If your site will be served from a subpath (not root domain):
 basePath: `/${repoName}`,
 assetPrefix: `/${repoName}/`,
};
module.exports = nextConfig;
</code></pre>
<blockquote>
<p>If deploying to https://<username>.github.io/<repo-name>/, you must set <code>basePath</code> and <code>assetPrefix</code>.</p>
</blockquote>
<blockquote>
<p>If deploying to a root user/organization site (https://<username>.github.io/), omit <code>basePath</code> and <code>assetPrefix</code>.</p>
</blockquote>
<h4 id="3-update-packagejson-scripts"><a class="heading-anchor" aria-hidden tabindex="-1" href="#3-update-packagejson-scripts"><span class="anchor-icon">#</span></a>3. Update <code>package.json</code> Scripts</h4>
<p>Add scripts for exporting and deploying:</p>
<pre><code class="hljs language-text">“scripts”: {
 “dev”: “next dev”,
 “build”: “next build”,
 “export”: “next export”,
 “predeploy”: “npm run build &#x26;&#x26; npm run export”,
 “deploy”: “gh-pages -d out”
}
</code></pre>
<h4 id="4-install-gh-pages"><a class="heading-anchor" aria-hidden tabindex="-1" href="#4-install-gh-pages"><span class="anchor-icon">#</span></a>4. Install <code>gh-pages</code></h4>
<pre><code class="hljs language-bash">npm install — save-dev gh-pages
</code></pre>
<h4 id="5-build-and-export-your-staticsite"><a class="heading-anchor" aria-hidden tabindex="-1" href="#5-build-and-export-your-staticsite"><span class="anchor-icon">#</span></a>5. Build and Export Your Static Site</h4>
<pre><code class="hljs language-bash">npm run predeploy
</code></pre>
<p>This will output your static site in the <code>out</code> directory.</p>
<h4 id="6-set-up-your-github-repository"><a class="heading-anchor" aria-hidden tabindex="-1" href="#6-set-up-your-github-repository"><span class="anchor-icon">#</span></a>6. Set Up Your GitHub Repository</h4>
<p>Create a repository on GitHub (e.g., <code>your-repo-name</code>).</p>
<p>Initialize git in your project if you haven’t:</p>
<pre><code class="hljs language-bash"> git init
 git remote add origin &#x3C;a href=”https://github.com/&#x3C;your-username>/&#x3C;your-repo-name>.git<span class="hljs-string">" class=”underline” target=”_blank”>https://github.com/&#x3C;your-username>/&#x3C;your-repo-name>.git&#x3C;/a>
 git add .
 git commit -m “Initial commit”
 git push -u origin main
</span></code></pre>
<h4 id="7-deploy-to-githubpages"><a class="heading-anchor" aria-hidden tabindex="-1" href="#7-deploy-to-githubpages"><span class="anchor-icon">#</span></a><strong>7. Deploy to GitHub Pages</strong></h4>
<pre><code class="hljs language-bash">npm run deploy
</code></pre>
<p>This will publish the contents of <code>out</code> to the <code>gh-pages</code> branch.</p>
<h4 id="8-configure-githubpages"><a class="heading-anchor" aria-hidden tabindex="-1" href="#8-configure-githubpages"><span class="anchor-icon">#</span></a><strong>8. Configure GitHub Pages</strong></h4>
<blockquote>
<blockquote>
<p>Go to your repository on GitHub.</p>
</blockquote>
</blockquote>
<blockquote>
<blockquote>
<p>Navigate to Settings > Pages.</p>
</blockquote>
</blockquote>
<blockquote>
<blockquote>
<p>Under Source, select the <code>gh-pages</code> branch and root (<code>/</code>).</p>
</blockquote>
</blockquote>
<blockquote>
<blockquote>
<p>Save.</p>
</blockquote>
</blockquote>
<h4 id="9-optional-set-homepage-in-packagejson"><a class="heading-anchor" aria-hidden tabindex="-1" href="#9-optional-set-homepage-in-packagejson"><span class="anchor-icon">#</span></a><strong>9. (Optional) Set <code>homepage</code> in <code>package.json</code></strong></h4>
<p>This isn’t required for Next.js, but may help with asset resolution:</p>
<pre><code class="hljs language-text">“homepage”: “&#x3C;a href=”https://&#x3C;your-username>.github.io/&#x3C;your-repo-name>/”” class=”underline” target=”_blank”>https://&#x3C;your-username>.github.io/&#x3C;your-repo-name>/”&#x3C;/a>
</code></pre>
<h4 id="10-access-yoursite"><a class="heading-anchor" aria-hidden tabindex="-1" href="#10-access-yoursite"><span class="anchor-icon">#</span></a><strong>10. Access Your Site</strong></h4>
<p>After a few moments, visit:</p>
<pre><code class="hljs language-text">https://&#x3C;your-username>.github.io/&#x3C;your-repo-name>/
</code></pre>
<h4 id="11-advanced-handle-client-side-routing"><a class="heading-anchor" aria-hidden tabindex="-1" href="#11-advanced-handle-client-side-routing"><span class="anchor-icon">#</span></a><strong>11. (Advanced) Handle Client-Side Routing</strong></h4>
<p>GitHub Pages serves only static files. For client-side routes (e.g., <code>/about</code>), ensure you have an <code>out/about/index.html</code>.</p>
<p>If you get 404s on client-side routes, you can:</p>
<p>Use <a href="https://nextjs.org/docs/pages/building-your-application/deploying/static-exports">next export</a> (it generates all static pages).</p>
<p>If you need a fallback, copy <code>out/index.html</code> to <code>out/404.html</code> after export:<br>
 cp out/index.html out/404.html<br>
 <br>
This helps GitHub Pages route unknown paths back to your app’s entry point.</p>
<h4 id="12-optional-customdomain"><a class="heading-anchor" aria-hidden tabindex="-1" href="#12-optional-customdomain"><span class="anchor-icon">#</span></a><strong>12. (Optional) Custom Domain</strong></h4>
<ul>
<li>Add a <code>CNAME</code> file to <code>out/</code> with your custom domain before deploying.</li>
<li>Or, configure custom domain in GitHub Pages settings.</li>
</ul>
<h4 id="13-troubleshooting-tips"><a class="heading-anchor" aria-hidden tabindex="-1" href="#13-troubleshooting-tips"><span class="anchor-icon">#</span></a><strong>13. (Troubleshooting &#x26; Tips)</strong></h4>
<ul>
<li>White page or broken CSS?</li>
<li>Double-check <code>basePath</code> and <code>assetPrefix</code> in <code>next.config.js</code>.</li>
<li>Ensure all links use Next.js <code>&#x3C;Link></code> or are prefixed with <code>basePath</code>.</li>
<li>Images not showing?</li>
<li>Use the correct path prefix.</li>
<li>404 on refresh?</li>
<li>Ensure all pages are statically exported.</li>
<li>Use the <code>404.html</code> trick above.</li>
</ul>

<h4 id="summary-workflow"><a class="heading-anchor" aria-hidden tabindex="-1" href="#summary-workflow"><span class="anchor-icon">#</span></a><strong>Summary Workflow</strong></h4>
<ol>
<li>Configure <code>next.config.js</code> for static export and subpath (if needed)</li>
<li>Add scripts to <code>package.json</code></li>
<li>Install <code>gh-pages</code></li>
<li>Build and export: <code>npm run build &#x26;&#x26; npm run export</code></li>
<li>Deploy: <code>npm run deploy</code></li>
<li>Set Pages source to <code>gh-pages</code> branch in GitHub</li>
<li>Visit your site!</li>
</ol>
