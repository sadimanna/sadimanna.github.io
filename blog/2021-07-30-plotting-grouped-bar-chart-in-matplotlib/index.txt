<p>In this article, we are going to learn how to draw grouped bar charts (a.k.a clustered bar charts or multi-series bar charts) in Python using the Matplotlib library. Without further delay, let’s jump straight into the code.</p>
<blockquote>
<p>The structuring of the code may differ on mobile and desktop! It is recommended to view in desktop mode when opened on mobile phones!</p>
</blockquote>
<h3 id="imports"><a class="heading-anchor" aria-hidden tabindex="-1" href="#imports"><span class="anchor-icon">#</span></a>Imports</h3>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> numpy <span class="hljs-keyword">as</span> np
<span class="hljs-keyword">import</span> pandas <span class="hljs-keyword">as</span> pd
<span class="hljs-keyword">import</span> matplotlib.pyplot <span class="hljs-keyword">as</span> plt
<span class="hljs-keyword">from</span> matplotlib <span class="hljs-keyword">import</span> colormaps
<span class="hljs-keyword">import</span> math
</code></pre>
<p>Now, for the sake of this article, let us consider, we have three discrete labels, for which we need to visualize the value of some property. Let us consider, these three labels to be three football seasons, e.g. 2018–2019, 2019–2020, 2020–2021, and we are going to plot goals scored by some famous players over these three years.</p>
<h3 id="data"><a class="heading-anchor" aria-hidden tabindex="-1" href="#data"><span class="anchor-icon">#</span></a>Data</h3>
<pre><code class="hljs language-text">Players        2018–2019 2019–2020 2020–2021
C. Ronaldo         21        31        29
L. Messi           36        25        30
Neymar Jr.         15        13         9
R. Lewandowski     22        34        41
K. Mbappe          33        18        27
R. Lukaku          12        23        24
K. Benzema         21        21        23
</code></pre>
<p>Compile this data into a DataFrame, or an array, according to your preference. Here, I am assuming that the name of the data frame is <em><strong>stats.</strong></em></p>
<h3 id="variables"><a class="heading-anchor" aria-hidden tabindex="-1" href="#variables"><span class="anchor-icon">#</span></a>Variables</h3>
<pre><code class="hljs language-text">w = 1.0
num_yrs = len(stats.columns) — 1 #stats.shape[1] - 1
num_plyrs = len(stats) #stats.shape[0]
</code></pre>
<h3 id="other-parameters"><a class="heading-anchor" aria-hidden tabindex="-1" href="#other-parameters"><span class="anchor-icon">#</span></a>Other parameters</h3>
<pre><code class="hljs language-text">first_tick = int(math.ceil((num_plyrs*w/2))) 
gap = num_plyrs*w + 1
x = np.array([first_tick + i*gap for i in range(num_yrs)])
</code></pre>
<h3 id="choosing-colors"><a class="heading-anchor" aria-hidden tabindex="-1" href="#choosing-colors"><span class="anchor-icon">#</span></a>Choosing Colors</h3>
<pre><code class="hljs language-text">colors = colormaps['inferno']
</code></pre>
<pre><code class="hljs language-text"># Deprecated
# colors = plt.cm.get_cmap(‘inferno’,num_plyrs)
</code></pre>
<h3 id="plotting"><a class="heading-anchor" aria-hidden tabindex="-1" href="#plotting"><span class="anchor-icon">#</span></a>Plotting</h3>
<pre><code class="hljs language-text">fig,ax = plt.subplots(1,1, figsize=(10,10))
</code></pre>
<pre><code class="hljs language-text">b = []
for i in range(num_plyrs):
    b.append(ax.bar(x - (i - num_plyrs/2 + 0.5)*w, 
             stats.loc[i].values[1:], 
             width=w, 
             color=colors(i), 
             align='center', 
             edgecolor = 'black', 
             linewidth = 1.0, 
             alpha=0.5))
</code></pre>
<pre><code class="hljs language-text">ax.legend([b_ for b_ in b], 
           stats['Players'].values.tolist(), 
           ncol = 3, 
           loc = 'best', 
           framealpha = 0.1)
           
ax.set_ylabel('Goals')
ax.set_xlabel('Players')
ax.set_title('Goals scored by players')
ax.set_xticks(x)
ax.set_xticklabels(stats.columns.values[1:])
</code></pre>
<pre><code class="hljs language-text">for i in range(num_plyrs):
    ax.bar_label(b[i], 
                 padding = 3, 
                 label_type='center', 
                 rotation = 'vertical')
</code></pre>
<pre><code class="hljs language-text">plt.show()
</code></pre>
