<p><img src="/images/blog/understanding-and-calculating-macs-and-flops-in-pytorch-mode/img1.jpeg" alt=""></p>
<p>As the complexity of deep learning models grows, understanding their computational demands becomes increasingly important. One key metric used to assess this is the number of <strong>FL</strong>oating <strong>P</strong>oint <strong>O</strong>perations per <strong>S</strong>econd (FLOPs). FLOPs provide an estimate of the computational cost of running a model, which can be crucial for optimizing performance, particularly when deploying models to resource-constrained environments. In this blog post, we’ll explore how to calculate FLOPs for a PyTorch model using the <em><code>****torchprofile****</code></em> and ‘<em><strong>calflops’</strong></em> libraries.</p>
<h3 id="what-areflops"><a class="heading-anchor" aria-hidden tabindex="-1" href="#what-areflops"><span class="anchor-icon">#</span></a>What are FLOPs?</h3>
<p>FLOPs represent the number of arithmetic operations required to execute a model. This includes operations like additions, multiplications, and other basic arithmetic computations. By understanding FLOPs, you can gain insights into the efficiency and performance of your model, enabling informed decisions about model optimization and deployment.</p>
<h3 id="why-calculate-flops"><a class="heading-anchor" aria-hidden tabindex="-1" href="#why-calculate-flops"><span class="anchor-icon">#</span></a>Why Calculate FLOPs?</h3>
<ol>
<li><strong>Optimization</strong>: Knowing the FLOPs can guide you in optimizing your model for faster inference times.</li>
<li><strong>Resource Allocation</strong>: Helps in determining the computational resources needed for model deployment.</li>
<li><strong>Comparison</strong>: Allows you to compare different models or architectures in terms of computational complexity.</li>
</ol>
<h3 id="calculating-flops-with-torchprofile"><a class="heading-anchor" aria-hidden tabindex="-1" href="#calculating-flops-with-torchprofile"><span class="anchor-icon">#</span></a>Calculating FLOPs with <code>torchprofile</code></h3>
<p>To calculate FLOPs in PyTorch, we can use the <em><code>****torchprofile****</code></em> library, which provides an easy-to-use interface for profiling PyTorch models. Here’s a step-by-step guide on how to do it.</p>
<h3 id="step-1-install-torchprofile"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-1-install-torchprofile"><span class="anchor-icon">#</span></a>Step 1: Install <code>torchprofile</code></h3>
<p>First, you’ll need to install the <em><code>torchprofile</code></em> library. This can be easily done using pip:</p>
<pre><code class="hljs language-bash">pip install torchprofile
</code></pre>
<h3 id="step-2-define-yourmodel"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-2-define-yourmodel"><span class="anchor-icon">#</span></a>Step 2: Define Your Model</h3>
<p>Ensure your model is defined as a subclass of <em><code>nn.Module</code></em> and has an implemented <em><code>forward</code></em> method. Here’s an example of a simple convolutional neural network:</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> torch 
<span class="hljs-keyword">import</span> torch.nn <span class="hljs-keyword">as</span> nn  
<span class="hljs-keyword">class</span> <span class="hljs-title class_">SimpleModel</span>(nn.Module):
    <span class="hljs-keyword">def</span> <span class="hljs-title function_">__init__</span>(<span class="hljs-params">self</span>):
        <span class="hljs-built_in">super</span>(SimpleModel, <span class="hljs-variable language_">self</span>).__init__()
        <span class="hljs-variable language_">self</span>.conv1 = nn.Conv2d(<span class="hljs-number">3</span>, <span class="hljs-number">16</span>, kernel_size=<span class="hljs-number">3</span>, stride=<span class="hljs-number">1</span>, padding=<span class="hljs-number">1</span>)
        <span class="hljs-variable language_">self</span>.conv2 = nn.Conv2d(<span class="hljs-number">16</span>, <span class="hljs-number">32</span>, kernel_size=<span class="hljs-number">3</span>, stride=<span class="hljs-number">1</span>, padding=<span class="hljs-number">1</span>)
        <span class="hljs-variable language_">self</span>.fc1 = nn.Linear(<span class="hljs-number">32</span>  <span class="hljs-number">32</span>  <span class="hljs-number">32</span>, <span class="hljs-number">10</span>)
    <span class="hljs-keyword">def</span> <span class="hljs-title function_">forward</span>(<span class="hljs-params">self, x</span>):
        x = <span class="hljs-variable language_">self</span>.conv1(x)
        x = <span class="hljs-variable language_">self</span>.conv2(x)
        x = x.view(x.size(<span class="hljs-number">0</span>), -<span class="hljs-number">1</span>)
        x = <span class="hljs-variable language_">self</span>.fc1(x)
        <span class="hljs-keyword">return</span> x
</code></pre>
<h3 id="step-3-calculate-flops"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-3-calculate-flops"><span class="anchor-icon">#</span></a>Step 3: Calculate FLOPs</h3>
<p>With your model defined, you can now use <em><code>torchprofile</code></em> to calculate FLOPs. Here’s how to do it:</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> torchprofile  

<span class="hljs-comment"># Create an instance of the model </span>
model = SimpleModel()  

<span class="hljs-comment"># Create a dummy input tensor with the appropriate shape </span>
input_tensor = torch.randn(<span class="hljs-number">1</span>, <span class="hljs-number">3</span>, <span class="hljs-number">32</span>, <span class="hljs-number">32</span>)  

<span class="hljs-comment"># Example for a 32x32 RGB image  </span>
<span class="hljs-comment"># Use torchprofile to calculate FLOPs </span>
macs = torchprofile.profile_macs(model, input_tensor)
</code></pre>
<h4 id="for-multipleinputs"><a class="heading-anchor" aria-hidden tabindex="-1" href="#for-multipleinputs"><span class="anchor-icon">#</span></a>For Multiple Inputs</h4>
<p>Utilise the ‘<em>args</em>’ argument in the <em><strong>profile_macs</strong></em> function</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> torchprofile  

<span class="hljs-comment"># Create an instance of the model </span>
model = SimpleModel()  

<span class="hljs-comment"># Create a dummy input tensor with the appropriate shape </span>
input_tensor = torch.randn(<span class="hljs-number">1</span>, <span class="hljs-number">3</span>, <span class="hljs-number">32</span>, <span class="hljs-number">32</span>)  

<span class="hljs-comment"># Example for two32x32 RGB image input</span>
<span class="hljs-comment"># Use torchprofile to calculate FLOPs </span>
macs = torchprofile.profile_macs(model, args= (input_tensor, input_tensor))
</code></pre>
<h3 id="key-points"><a class="heading-anchor" aria-hidden tabindex="-1" href="#key-points"><span class="anchor-icon">#</span></a>Key Points:</h3>
<ul>
<li>Input Shape: Ensure the input tensor matches the expected input shape of your model. Typically, a batch size of 1 is used for MACs calculation.</li>
<li>Multiple input is also supported through the <em>args</em> argument.</li>
</ul>
<h3 id="calculating-flops-with-calflops"><a class="heading-anchor" aria-hidden tabindex="-1" href="#calculating-flops-with-calflops"><span class="anchor-icon">#</span></a>Calculating FLOPS with ‘calflops’</h3>
<p><em><code>calflops</code></em> is another library that can be used to calculate the number of floating-point operations (FLOPs) for PyTorch models. It provides a simple interface to estimate FLOPs and the number of parameters in a model.</p>
<h3 id="step-1-installation"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-1-installation"><span class="anchor-icon">#</span></a>Step 1. Installation</h3>
<p>First, you need to install the <em><code>calflops</code></em> library. As of my last update, it might not be available on PyPI directly, so you may need to install it from its repository if it’s hosted on platforms like GitHub. Here’s a general way to do it:</p>
<pre><code class="hljs language-bash">pip install calflops
</code></pre>
<h3 id="step-2-definemodel"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-2-definemodel"><span class="anchor-icon">#</span></a>Step 2. Define Model</h3>
<p>Already done above, so we will skip this step.</p>
<h3 id="step-3-calculate-flops-1"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-3-calculate-flops-1"><span class="anchor-icon">#</span></a>Step 3: Calculate FLOPs</h3>
<p>Calflops provides many features, among which calculating FLOPs of an HF model using an access token is the most interesting. However, we will leave that exploration to the user and focus on a simple model here, for introduction.</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> calflops
batch_size = <span class="hljs-number">1</span>
input_shape = (batch_size, <span class="hljs-number">3</span>, <span class="hljs-number">224</span>, <span class="hljs-number">224</span>)
flops, macs, params = calflops.calculate_flops(model=model, 
                                      input_shape=input_shape,
                                      output_as_string=<span class="hljs-literal">True</span>,
                                      output_precision=<span class="hljs-number">4</span>)
<span class="hljs-built_in">print</span>(<span class="hljs-string">"Model FLOPs:%s   MACs:%s   Params:%s \n"</span> %(flops, macs, params))
</code></pre>
<p>There are also provisions for outputting a full report with detailed analysis in <em><strong>calflops</strong></em> library, which makes it better than <em><strong>torchprofile</strong></em>.</p>

<p>Similar to torchprofile, if the model requires multiple inputs, it can be provided using <em><strong>args</strong></em> (<strong>list</strong>) or <em><strong>kwargs</strong></em> (<strong>dict</strong>) arguments.</p>
<h3 id="conclusion"><a class="heading-anchor" aria-hidden tabindex="-1" href="#conclusion"><span class="anchor-icon">#</span></a>Conclusion</h3>
<p>Calculating FLOPs is a valuable step in understanding the computational demands of your models. Whether you’re comparing different architectures or preparing a deployment model, knowing the FLOPs can provide critical insights into your model’s performance and efficiency.</p>
<p>By integrating FLOPs calculation into your workflow, you can ensure that your models are not only accurate but also efficient, paving the way for successful deployment in real-world applications.</p>
