<p>In medical imaging, handling large datasets efficiently is crucial for storage and processing purposes. Neuroimaging Informatics Technology Initiative (NIfTI) files, commonly used for storing MRI data, can be quite large. Compressing these files into <em><code>.nii.gz</code></em> format saves disk space and facilitates faster data transfers and processing. In this blog, we’ll explore how to use two popular Python libraries — <strong>NiBabel</strong> and <strong>SimpleITK</strong>— to compress <em><code>.nii</code></em> files, achieving size reductions up to tenfold.</p>
<p><strong>Motivation:</strong> These methods are particularly useful when handling large datasets like BraTS. Specifically speaking, I noticed a discrepancy in the dataset size between BraTS2020 and BraTS2021 datasets downloaded from different sources. While my particular application required using the T1CE planes of the BraTS2020 dataset, the total size occupied by the 369 T1CE scans was about 10 GB, and the whole dataset, including all four planes, FLAIR, T1, T1CE, and T2, amounted to more than 30 GB. But I noticed that the whole BraTS2021 dataset, with about 1500 scans, only occupied about 10 GB of space on the disk.</p>
<p>Upon careful inspection, I came to observe that I had completely skipped noticing that the two datasets that I had downloaded did not have the same file extension, but both were read by SimpleITK or NiBabel without any errors. While the BraTS2020 dataset files had <em>.nii</em> file extension, the BraTS2021 dataset files had <em>.nii.gz</em> which explained the discrepancy in size.</p>
<p>If having a more compressed file did not cause any issues in the pipeline, why not convert the BraTS2020 dataset into <em>.nii.gz</em> format, which would enable me to transfer the whole dataset more efficiently. After converting the BraTS2020 dataset files from .nii to .nii.gz, the dataset size reduced to 3.2 GB from about 30 GB (almost 10 times).</p>
<h4 id="why-compress-niftifiles"><a class="heading-anchor" aria-hidden tabindex="-1" href="#why-compress-niftifiles"><span class="anchor-icon">#</span></a>Why Compress NIfTI Files?</h4>
<p>Compressing <em><code>.nii</code></em> files to <em><code>.nii.gz</code></em> format offers several advantages:</p>
<ul>
<li>Reduced Storage Space: The compressed format significantly reduces file size, conserving disk space.</li>
<li>Enhanced Performance: Smaller files are quicker to read and write, improving data processing speed.</li>
<li>Ease of Sharing: Reduced file sizes make it easier to share datasets with collaborators.</li>
</ul>
<h4 id="using-nibabel-for-compression"><a class="heading-anchor" aria-hidden tabindex="-1" href="#using-nibabel-for-compression"><span class="anchor-icon">#</span></a>Using NiBabel for Compression</h4>
<p>NiBabel is a powerful library for reading and writing NIfTI files. Here’s how you can use it to compress <em><code>.nii</code></em> files:</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> nibabel <span class="hljs-keyword">as</span> nib

<span class="hljs-keyword">def</span> <span class="hljs-title function_">compress_nii_to_niigz</span>(<span class="hljs-params">input_file, output_file</span>):
    <span class="hljs-comment"># Load the .nii file using NiBabel </span>
    nii_image = nib.load(input_file)
    <span class="hljs-comment"># Save the image in .nii.gz format </span>
    output_file = input_file.replace(<span class="hljs-string">'.nii'</span>, <span class="hljs-string">'.nii.gz'</span>)
    nib.save(nii_image, output_file)
    <span class="hljs-built_in">print</span>(<span class="hljs-string">f"Compressed <span class="hljs-subst">{input_file}</span> to <span class="hljs-subst">{output_file}</span>"</span>)

<span class="hljs-comment"># Example usage </span>
<span class="hljs-keyword">if</span> __name__ == <span class="hljs-string">'__main__'</span>:
    compress_nii_to_niigz(<span class="hljs-string">'/path/to/example.nii'</span>)
</code></pre>
<h4 id="using-simpleitk-for-compression"><a class="heading-anchor" aria-hidden tabindex="-1" href="#using-simpleitk-for-compression"><span class="anchor-icon">#</span></a>Using SimpleITK for Compression</h4>
<p>SimpleITK, a simplified layer built on top of the Insight Segmentation and Registration Toolkit (ITK), also provides tools for handling NIfTI files:</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> SimpleITK <span class="hljs-keyword">as</span> sitk

<span class="hljs-keyword">def</span> <span class="hljs-title function_">compress_nii_to_niigz_sitk</span>(<span class="hljs-params">input_file, output_file</span>):
    <span class="hljs-comment"># Read the .nii file using SimpleITK </span>
    image = sitk.ReadImage(input_file) 
    <span class="hljs-comment"># Write the image in .nii.gz format </span>
    output_file = input_file.replace(<span class="hljs-string">'.nii'</span>, <span class="hljs-string">'.nii.gz'</span>)
    sitk.WriteImage(image, output_file) 
    <span class="hljs-built_in">print</span>(<span class="hljs-string">f"Compressed <span class="hljs-subst">{input_file}</span> to <span class="hljs-subst">{output_file}</span>"</span>) 

<span class="hljs-comment"># Example usage </span>

</code></pre>
<h4 id="conclusion"><a class="heading-anchor" aria-hidden tabindex="-1" href="#conclusion"><span class="anchor-icon">#</span></a>Conclusion</h4>
<p>Both <strong>NiBabel</strong> and <strong>SimpleITK</strong> offer straightforward methods to compress <em><code>.nii</code></em> files into <em><code>.nii.gz</code></em> format, achieving significant reductions in file size. Whether you’re managing large neuroimaging datasets or simply looking to optimise your data storage, these tools provide efficient solutions to streamline your workflow. By adopting compressed formats, you can enhance your data handling capabilities, making it easier to store, process, and share valuable medical imaging data.</p>
