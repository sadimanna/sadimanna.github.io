<p>In this article, we will look at a short example of how we can automate running ablation study experiments on our deep learning models using batch scripts in Windows.</p>
<blockquote>
<p>Step 1</p>
</blockquote>
<p>Create a <em><strong>.bat</strong></em> file in your editor</p>
<blockquote>
<p>Step 2: Identify the hyper-parameters you want to sweep over in your experiments</p>
</blockquote>
<p>For this article, let us consider the hyper-parameter to be λ. Also, we would like to see the effect of batch size for each λ value.</p>
<pre><code class="hljs language-text">@echo off
setlocal EnableDelayedExpansion
set lambda=2 10 50 100
set bs=128 256 512
set /a exprun = 1
for %%i in (%lambda%) do (
    for %%j in (%bs%) do (
        echo lambda=%%i/100
        echo bs=%%j
        set /a exprun=!exprun!+1
        echo !exprun!
        python train.py --lambda %%i --bs %%j --run !exprun!
    )
)
endlocal
</code></pre>
<p>In the above code, we pass the arguments <em><strong>lambda</strong></em> and <em><strong>bs</strong></em> to the python file <em><strong>trian.py</strong></em> and also increment our experiment number counter <em><strong>exprun.</strong></em></p>
<h4 id="for-loop"><a class="heading-anchor" aria-hidden tabindex="-1" href="#for-loop"><span class="anchor-icon">#</span></a>for loop</h4>
<pre><code class="hljs language-text">for %%i in (%lambda%) do (
...
)
</code></pre>
<p>Iterates over the elements in the list <em><strong>lambda</strong></em></p>
<h4 id="set"><a class="heading-anchor" aria-hidden tabindex="-1" href="#set"><span class="anchor-icon">#</span></a>set</h4>
<pre><code class="hljs language-text">set /a exprun = 1
</code></pre>
<p>Sets the value <em><strong>1</strong></em> to the environment variable <em><strong>exprun.</strong></em></p>
<p>Using <strong>/a</strong> sets <code>&#x3C;string></code> to a numerical expression that is evaluated.</p>
<p><strong>setlocal</strong></p>
<p>Detailed explanation can be found here <a href="https://ss64.com/nt/setlocal.html">https://ss64.com/nt/setlocal.html</a></p>
