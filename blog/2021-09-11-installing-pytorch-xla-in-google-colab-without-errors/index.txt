<p>Very often people working on Google Colab, try installing <strong>torch-xla</strong> using the following command:</p>
<pre><code class="hljs language-text">!pip install cloud-tpu-client==0.10 https://storage.googleapis.com/tpu-pytorch/wheels/torch_xla-1.9-cp37-cp37m-linux_x86_64.whl
</code></pre>
<p><strong>EDIT</strong>:</p>
<p>As of 14th September 2021, the <strong>torch-xla-1.9</strong> wheel has been fixed, as reported in the GitHub Issue tab (<a href="https://github.com/pytorch/xla/issues/3121"><strong>#3121</strong></a>).</p>
<p>So, now anyone can just use</p>
<pre><code class="hljs language-text">!pip install cloud-tpu-client==0.10 https://storage.googleapis.com/tpu-pytorch/wheels/torch_xla-1.9-cp37-cp37m-linux_x86_64.whl
</code></pre>
<p>it without any errors!!</p>

<p>As of now, it seems that we can get rid of this error by simply downgrading PyTorch to <strong>torch-1.8.2+cpu</strong></p>
<p>To match the versions, we need to install <strong>torch-xla-1.8</strong></p>
<pre><code class="hljs language-text">!pip install cloud-tpu-client==0.10 https://storage.googleapis.com/tpu-pytorch/wheels/torch_xla-1.8-cp37-cp37m-linux_x86_64.whl
