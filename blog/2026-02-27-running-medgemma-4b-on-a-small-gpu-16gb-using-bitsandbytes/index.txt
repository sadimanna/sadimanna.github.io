<p>Large multimodal models usually demand serious hardware. A 4B parameter model in full precision occupies roughly 8GB just for weights — and that’s before accounting for activations and KV cache during generation.</p>
<p>If you are using Google Colab (T4, 15GB VRAM) or a consumer GPU like an RTX 3060 (12GB), you quickly run into memory limits.</p>
<p>This is where <strong>bitsandbytes</strong> becomes extremely powerful.</p>
<p>Instead of storing each model parameter in 16 bits, we compress them to 8-bit or 4-bit — dramatically reducing memory consumption — while preserving most of the model’s intelligence.</p>
<p>In this tutorial, we will run <strong>MedGemma-4B-IT</strong> using:</p>
<ul>
<li>16-bit (baseline)</li>
<li>8-bit quantization</li>
<li>4-bit NF4 quantization</li>
</ul>
<p>And we’ll explain what each function actually does internally.</p>
<h3 id="why-use-bitsandbytes"><a class="heading-anchor" aria-hidden tabindex="-1" href="#why-use-bitsandbytes"><span class="anchor-icon">#</span></a>Why Use BitsAndBytes?</h3>
<p>BitsAndBytes integrates directly into the HuggingFace Transformers stack. That means:</p>
<ul>
<li>You still use PyTorch</li>
<li>You still use model.generate()</li>
<li>You can fine-tune later (QLoRA)</li>
<li>You keep multimodal compatibility</li>
</ul>
<p>Unlike CPU-based runtimes, this path is GPU-optimized and ideal for research.</p>
<h3 id="step-1installing-the-required-libraries"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-1installing-the-required-libraries"><span class="anchor-icon">#</span></a>Step 1 — Installing the Required Libraries</h3>
<pre><code class="hljs language-bash">pip install transformers accelerate bitsandbytes sentencepiece
</code></pre>
<p>Here’s what each library contributes:</p>
<ul>
<li><strong>transformers</strong> loads model architecture and handles generation.</li>
<li><strong>accelerate</strong> automatically decides whether tensors go to CPU or GPU.</li>
<li><strong>bitsandbytes</strong> replaces standard linear layers with quantized kernels.</li>
<li><strong>sentencepiece</strong> supports the tokenizer backend used by Gemma.</li>
</ul>
<p>When you import:</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">from</span> transformers <span class="hljs-keyword">import</span> AutoProcessor, AutoModelForImageTextToText
<span class="hljs-keyword">from</span> transformers <span class="hljs-keyword">import</span> BitsAndBytesConfig
</code></pre>
<p>You are pulling in abstractions that dynamically construct the correct model class based on configuration metadata stored on HuggingFace.</p>
<h3 id="step-2loading-the-model-in-16-bit-baseline"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-2loading-the-model-in-16-bit-baseline"><span class="anchor-icon">#</span></a>Step 2 — Loading the Model in 16-bit (Baseline)</h3>
<pre><code class="hljs language-text">model = AutoModelForImageTextToText.from_pretrained(
    model_id,
    torch_dtype=torch.float16,
    device_map="auto",
)
</code></pre>
<p>Let’s unpack this.</p>
<h3 id="what-does-from_pretrained-actuallydo"><a class="heading-anchor" aria-hidden tabindex="-1" href="#what-does-from_pretrained-actuallydo"><span class="anchor-icon">#</span></a>What does from_pretrained() actually do?</h3>
<p>Internally, it:</p>
<ol>
<li>Downloads the model configuration (config.json)</li>
<li>Instantiates the architecture class</li>
<li>Loads weight tensors into memory</li>
<li>Places them on the appropriate device</li>
</ol>
<p>When you set:</p>
<pre><code class="hljs language-text">torch_dtype=torch.float16
</code></pre>
<p>All weight tensors are loaded in FP16 format (2 bytes per parameter).</p>
<p>For a 4B model:</p>
<pre><code class="hljs language-text">4 billion × 2 bytes ≈ 8GB
</code></pre>
<p>That’s just weights — activations during inference increase this.</p>
<h3 id="what-does-device_mapauto-do"><a class="heading-anchor" aria-hidden tabindex="-1" href="#what-does-device_mapauto-do"><span class="anchor-icon">#</span></a>What does device_map="auto" do?</h3>
<p>This uses Accelerate to inspect available GPU memory and distribute layers accordingly. If memory is tight, some layers may spill to the CPU automatically.</p>
<h3 id="step-38-bit-quantization"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-38-bit-quantization"><span class="anchor-icon">#</span></a>Step 3–8-bit Quantization</h3>
<pre><code class="hljs language-text">bnb_config = BitsAndBytesConfig(load_in_8bit=True)
model = AutoModelForImageTextToText.from_pretrained(
    model_id,
    quantization_config=bnb_config,
    device_map="auto"
)
</code></pre>
<p>Now something interesting happens.</p>
<p>When load_in_8bit=True is passed:</p>
<ul>
<li>Standard nn.Linear layers are replaced with Linear8bitLt</li>
<li>Weight tensors are stored in 8-bit integer format</li>
<li>During the forward pass, they are dynamically dequantized into floats for computation</li>
</ul>
<blockquote>
<p><strong>The key insight:</strong><br>
Weights are compressed in memory, but computation still happens in higher precision.</p>
</blockquote>
<p>This cuts memory roughly in half while preserving numerical stability. In practice:</p>
<ul>
<li>VRAM drops from ~12GB → ~8–9GB</li>
<li>Speed impact is minimal</li>
<li>Output quality remains very close to FP16</li>
</ul>
<h3 id="step-44-bit-nf4-quantization"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-44-bit-nf4-quantization"><span class="anchor-icon">#</span></a>Step 4–4-bit NF4 Quantization</h3>
<pre><code class="hljs language-text">bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.bfloat16
)
</code></pre>
<p>Now we move into more aggressive compression.</p>
<h3 id="what-isnf4"><a class="heading-anchor" aria-hidden tabindex="-1" href="#what-isnf4"><span class="anchor-icon">#</span></a>What is NF4?</h3>
<p>NF4 (NormalFloat4) is not naive 4-bit rounding.</p>
<p>Instead:</p>
<ul>
<li>It assumes weights follow a normal distribution</li>
<li>Uses learned scaling factors</li>
<li>Minimizes quantization error statistically</li>
</ul>
<p>Internally, during inference:</p>
<ul>
<li>Weights are stored as 4-bit packed tensors</li>
<li>Each block has scaling metadata</li>
<li>They are reconstructed on-the-fly during matrix multiplication</li>
</ul>
<p>This allows a 4B model to fit in ~5–7GB VRAM. This is how Colab T4 can run MedGemma comfortably.</p>
<h3 id="step-5preparing-multimodal-input"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-5preparing-multimodal-input"><span class="anchor-icon">#</span></a>Step 5 — Preparing Multimodal Input</h3>
<pre><code class="hljs language-text">processor = AutoProcessor.from_pretrained(model_id)
</code></pre>
<p>The AutoProcessor abstracts:</p>
<ul>
<li>Tokenizer</li>
<li>Image preprocessor</li>
<li>Chat formatting logic</li>
</ul>
<p>When you call:</p>
<pre><code class="hljs language-text">processor.apply_chat_template(...)
</code></pre>
<p>Internally, it:</p>
<ol>
<li>Formats messages into structured tokens</li>
<li>Inserts special tokens like &#x3C;start_of_turn></li>
<li>Encodes images into embedding tensors</li>
<li>Returns a PyTorch dictionary ready for generation</li>
<li>Example:</li>
</ol>
<pre><code class="hljs language-text">&#x3C;start_of_turn>system
You are an expert radiologist.
&#x3C;end_of_turn>
&#x3C;start_of_turn>user
Describe this X-ray
&#x3C;start_of_image>
&#x3C;end_of_turn>
&#x3C;start_of_turn>model
</code></pre>
<p>This is essential for multimodal models — you cannot simply pass raw text.</p>
<h3 id="step-6generation"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-6generation"><span class="anchor-icon">#</span></a>Step 6 — Generation</h3>
<pre><code class="hljs language-text">generation = model.generate(**inputs, max_new_tokens=200)
</code></pre>
<p>Under the hood:</p>
<ul>
<li>The model builds a KV cache</li>
<li>Attention layers reuse past keys and values</li>
<li>Tokens are generated autoregressively</li>
<li>Sampling or greedy decoding is applied</li>
</ul>
<p>Quantized models still use the same generation logic — only weight storage differs.</p>
<h3 id="full-script"><a class="heading-anchor" aria-hidden tabindex="-1" href="#full-script"><span class="anchor-icon">#</span></a>Full Script</h3>
<pre><code class="hljs language-python"><span class="hljs-comment"># =========================================================</span>
<span class="hljs-comment"># MedGemma-4B-IT — Transformers + BitsAndBytes Version</span>
<span class="hljs-comment"># =========================================================</span>
<span class="hljs-comment"># Install if needed:</span>
<span class="hljs-comment"># pip install transformers accelerate bitsandbytes sentencepiece</span>
<span class="hljs-keyword">import</span> torch
<span class="hljs-keyword">import</span> gc
<span class="hljs-keyword">from</span> transformers <span class="hljs-keyword">import</span> AutoProcessor, AutoModelForImageTextToText, BitsAndBytesConfig,
<span class="hljs-keyword">from</span> PIL <span class="hljs-keyword">import</span> Image
<span class="hljs-keyword">import</span> requests

model_id = <span class="hljs-string">"google/medgemma-4b-it"</span>
<span class="hljs-comment"># — — — — — — — — — — — — — — — — — — — — — — — — — — — — -</span>
<span class="hljs-comment"># Utility: Print GPU memory usage</span>
<span class="hljs-comment"># — — — — — — — — — — — — — — — — — — — — — — — — — — — — -</span>
<span class="hljs-keyword">def</span> <span class="hljs-title function_">print_vram</span>(<span class="hljs-params">stage</span>):
  <span class="hljs-keyword">if</span> torch.cuda.is_available():
    allocated = torch.cuda.memory_allocated() / <span class="hljs-number">1024</span>**<span class="hljs-number">3</span>
    reserved = torch.cuda.memory_reserved() / <span class="hljs-number">1024</span>**<span class="hljs-number">3</span>
    <span class="hljs-built_in">print</span>(<span class="hljs-string">f"\n<span class="hljs-subst">{stage}</span>"</span>)
    <span class="hljs-built_in">print</span>(<span class="hljs-string">f"Allocated: <span class="hljs-subst">{allocated:<span class="hljs-number">.2</span>f}</span> GB"</span>)
    <span class="hljs-built_in">print</span>(<span class="hljs-string">f"Reserved : <span class="hljs-subst">{reserved:<span class="hljs-number">.2</span>f}</span> GB"</span>)
    <span class="hljs-built_in">print</span>(<span class="hljs-string">"-"</span> * <span class="hljs-number">40</span>)
  <span class="hljs-keyword">else</span>:
    <span class="hljs-built_in">print</span>(<span class="hljs-string">"CUDA not available."</span>)

<span class="hljs-comment"># — — — — — — — — — — — — — — — — — — — — — — — — — — — — -</span>
<span class="hljs-comment"># Load Model (4bit, 8bit, or 16bit)</span>
<span class="hljs-comment"># — — — — — — — — — — — — — — — — — — — — — — — — — — — — -</span>
<span class="hljs-keyword">def</span> <span class="hljs-title function_">load_model</span>(<span class="hljs-params">quant=<span class="hljs-literal">None</span></span>):
  gc.collect()
  <span class="hljs-keyword">if</span> torch.cuda.is_available():
    torch.cuda.empty_cache()

  <span class="hljs-keyword">if</span> quant == <span class="hljs-string">"4bit"</span>:
    <span class="hljs-built_in">print</span>(<span class="hljs-string">"Loading 4-bit NF4 quantized model..."</span>)
    bnb_config = BitsAndBytesConfig(
                                    load_in_4bit=<span class="hljs-literal">True</span>,
                                    bnb_4bit_quant_type=<span class="hljs-string">"nf4"</span>,
                                    bnb_4bit_compute_dtype=torch.bfloat16,
                                    )
    model = AutoModelForImageTextToText.from_pretrained(
                                      model_id,
                                      quantization_config=bnb_config,
                                      device_map=<span class="hljs-string">"auto"</span>,
                                      )
  <span class="hljs-keyword">elif</span> quant == <span class="hljs-string">"8bit"</span>:
    <span class="hljs-built_in">print</span>(<span class="hljs-string">"Loading 8-bit quantized model..."</span>)
    bnb_config = BitsAndBytesConfig(load_in_8bit=<span class="hljs-literal">True</span>)
    model = AutoModelForImageTextToText.from_pretrained(
                                      model_id,
                                      quantization_config=bnb_config,
                                      device_map=<span class="hljs-string">"auto"</span>,
                                      )
  <span class="hljs-keyword">else</span>:
    <span class="hljs-built_in">print</span>(<span class="hljs-string">"Loading FP16 model..."</span>)
    model = AutoModelForImageTextToText.from_pretrained(
                                      model_id,
                                      torch_dtype=torch.float16,
                                      device_map=”auto”,
                                      )

  print_vram(f”After loading ({quant <span class="hljs-keyword">or</span> ‘fp16’})”)
  <span class="hljs-keyword">return</span> model

<span class="hljs-comment"># — — — — — — — — — — — — — — — — — — — — — — — — — — — — -</span>
<span class="hljs-comment"># Select quantization mode</span>
<span class="hljs-comment"># Options: None (FP16), “8bit”, “4bit”</span>
<span class="hljs-comment"># — — — — — — — — — — — — — — — — — — — — — — — — — — — — -</span>
quant_mode = <span class="hljs-string">"8bit"</span> <span class="hljs-comment"># change to “4bit” or None</span>
model = load_model(quant=quant_mode)
processor = AutoProcessor.from_pretrained(model_id)
<span class="hljs-comment"># — — — — — — — — — — — — — — — — — — — — — — — — — — — — -</span>
<span class="hljs-comment"># Load sample image</span>
<span class="hljs-comment"># — — — — — — — — — — — — — — — — — — — — — — — — — — — — -</span>
image_url = <span class="hljs-string">"https://upload.wikimedia.org/wikipedia/commons/c/c8/Chest_Xray_PA_3-8-2010.png"</span>
image = Image.<span class="hljs-built_in">open</span>(requests.get(image_url, stream=<span class="hljs-literal">True</span>).raw)
<span class="hljs-comment"># — — — — — — — — — — — — — — — — — — — — — — — — — — — — -</span>
<span class="hljs-comment"># Construct multimodal chat messages</span>
<span class="hljs-comment"># — — — — — — — — — — — — — — — — — — — — — — — — — — — — -</span>
messages = [
  {
    <span class="hljs-string">"role"</span>: <span class="hljs-string">"system"</span>,
    <span class="hljs-string">"content"</span>: [{<span class="hljs-string">"type"</span>: <span class="hljs-string">"text"</span>, <span class="hljs-string">"text"</span>: <span class="hljs-string">"You are an expert radiologist."</span>}],
  },
  {
    <span class="hljs-string">"role"</span>: <span class="hljs-string">"user"</span>,
    <span class="hljs-string">"content"</span>: [
      {<span class="hljs-string">"type"</span>: <span class="hljs-string">"text"</span>, <span class="hljs-string">"text"</span>: <span class="hljs-string">"Describe this X-ray."</span>},
      {<span class="hljs-string">"type"</span>: <span class="hljs-string">"image"</span>, <span class="hljs-string">"image"</span>: image},
                ],
  },
]
<span class="hljs-comment"># — — — — — — — — — — — — — — — — — — — — — — — — — — — — -</span>
<span class="hljs-comment"># Prepare model inputs using chat template</span>
<span class="hljs-comment"># — — — — — — — — — — — — — — — — — — — — — — — — — — — — -</span>
inputs = processor.apply_chat_template(
                                      messages,
                                      add_generation_prompt=<span class="hljs-literal">True</span>,
                                      tokenize=<span class="hljs-literal">True</span>,
                                      return_dict=<span class="hljs-literal">True</span>,
                                      return_tensors=<span class="hljs-string">"pt"</span>,
                                      )
inputs = inputs.to(model.device)
input_len = inputs[<span class="hljs-string">"input_ids"</span>].shape[-<span class="hljs-number">1</span>]
<span class="hljs-comment"># — — — — — — — — — — — — — — — — — — — — — — — — — — — — -</span>
<span class="hljs-comment"># Generate response</span>
<span class="hljs-comment"># — — — — — — — — — — — — — — — — — — — — — — — — — — — — -</span>
torch.cuda.reset_peak_memory_stats()
<span class="hljs-keyword">with</span> torch.inference_mode():
  output = model.generate(
                          **inputs,
                          max_new_tokens=<span class="hljs-number">200</span>,
                          do_sample=<span class="hljs-literal">False</span>,
                          )
  generated_tokens = output[<span class="hljs-number">0</span>][input_len:]
  decoded = processor.decode(generated_tokens, skip_special_tokens=<span class="hljs-literal">True</span>)
<span class="hljs-built_in">print</span>(<span class="hljs-string">"\nModel Response:\n"</span>)
<span class="hljs-built_in">print</span>(decoded)
<span class="hljs-keyword">if</span> torch.cuda.is_available():
  peak = torch.cuda.max_memory_allocated() / <span class="hljs-number">1024</span>**<span class="hljs-number">3</span>
  <span class="hljs-built_in">print</span>(<span class="hljs-string">f"\nPeak VRAM during generation: <span class="hljs-subst">{peak:<span class="hljs-number">.2</span>f}</span> GB"</span>)
</code></pre>
<h3 id="sample-output"><a class="heading-anchor" aria-hidden tabindex="-1" href="#sample-output"><span class="anchor-icon">#</span></a>Sample Output</h3>
<pre><code class="hljs language-text">Okay, based on the image provided, here’s a description of the X-ray: 
**Overall Impression:** The X-ray shows a standard chest view,
