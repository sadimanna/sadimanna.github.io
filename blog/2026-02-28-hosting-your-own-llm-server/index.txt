11:T59ca,<h4 id="sending-text-and-files-to-a-local-model-using-fastapi-and-llama-server"><a class="heading-anchor" aria-hidden tabindex="-1" href="#sending-text-and-files-to-a-local-model-using-fastapi-and-llama-server"><span class="anchor-icon">#</span></a>Sending Text and Files to a Local Model Using FastAPI and llama-server</h4>
<p><img src="/images/blog/hosting-your-own-llm-server/img1.png" alt=""></p>
<p>Large language models are easy to run locally now. But running a model is not the same as <strong>serving</strong> it.</p>
<p>If you want to build real applications, you must learn how to:</p>
<ul>
<li>Accept HTTP requests</li>
<li>Parse JSON and multipart form data</li>
<li>Handle binary file uploads</li>
<li>Forward inputs to an LLM</li>
<li>Return structured responses</li>
</ul>
<p>In this tutorial, we’ll build production-style servers for:</p>
<ol>
<li><strong>Text-only LLM</strong></li>
<li><strong>Multimodal LLM (text + image)</strong></li>
</ol>
<p>We’ll implement this in two ways:</p>
<ul>
<li>✅ Using <strong>FastAPI + Transformers</strong></li>
<li>✅ Using <strong>FastAPI + llama-cpp (GGUF)</strong></li>
<li>✅ Using <strong>llama-server (native llama.cpp server)</strong></li>
</ul>
<p>All examples follow proper multipart/form-data format for file uploads.</p>
<h3 id="architecture-overview"><a class="heading-anchor" aria-hidden tabindex="-1" href="#architecture-overview"><span class="anchor-icon">#</span></a>Architecture Overview</h3>
<pre><code class="hljs language-text">Client (curl / browser / app)
        ↓
HTTP Request (JSON or multipart)
        ↓
FastAPI or llama-server
        ↓
LLM (Transformers or GGUF)
        ↓
Response
</code></pre>
<h3 id="part-1fastapi--transformers-text-only-llm"><a class="heading-anchor" aria-hidden tabindex="-1" href="#part-1fastapi--transformers-text-only-llm"><span class="anchor-icon">#</span></a>Part 1 — FastAPI + Transformers (Text-Only LLM)</h3>
<p>We’ll start with a text-only model.</p>
<h3 id="install"><a class="heading-anchor" aria-hidden tabindex="-1" href="#install"><span class="anchor-icon">#</span></a>Install</h3>
<pre><code class="hljs language-bash">pip install fastapi uvicorn transformers torch
</code></pre>
<h3 id="server-code-text-only"><a class="heading-anchor" aria-hidden tabindex="-1" href="#server-code-text-only"><span class="anchor-icon">#</span></a>Server Code (Text-Only)</h3>
<pre><code class="hljs language-python"><span class="hljs-comment"># server_text.py</span>
<span class="hljs-keyword">from</span> fastapi <span class="hljs-keyword">import</span> FastAPI
<span class="hljs-keyword">from</span> pydantic <span class="hljs-keyword">import</span> BaseModel
<span class="hljs-keyword">from</span> transformers <span class="hljs-keyword">import</span> AutoTokenizer, AutoModelForCausalLM
<span class="hljs-keyword">import</span> torch

app = FastAPI()

model_id = <span class="hljs-string">"openai-community/gpt2"</span>

tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(model_id)
model.<span class="hljs-built_in">eval</span>()

<span class="hljs-keyword">class</span> <span class="hljs-title class_">ChatRequest</span>(<span class="hljs-title class_ inherited__">BaseModel</span>):
    message: <span class="hljs-built_in">str</span>


<span class="hljs-meta">@app.post(<span class="hljs-params"><span class="hljs-string">"/chat"</span></span>)</span>
<span class="hljs-keyword">async</span> <span class="hljs-keyword">def</span> <span class="hljs-title function_">chat</span>(<span class="hljs-params">req: ChatRequest</span>):
    inputs = tokenizer(req.message, return_tensors=<span class="hljs-string">"pt"</span>)

    <span class="hljs-keyword">with</span> torch.no_grad():
        output = model.generate(**inputs, max_new_tokens=<span class="hljs-number">100</span>)
    
    response = tokenizer.decode(output[<span class="hljs-number">0</span>], skip_special_tokens=<span class="hljs-literal">True</span>)

    <span class="hljs-keyword">return</span> {<span class="hljs-string">"response"</span>: response}
</code></pre>

<p>Now, let’s serve a multimodal model like MedGemma.</p>
<p>We must use multipart/form-data because we are sending binary images.</p>
<h3 id="install-1"><a class="heading-anchor" aria-hidden tabindex="-1" href="#install-1"><span class="anchor-icon">#</span></a>Install</h3>

</code></pre>
<h3 id="server-code-text-image"><a class="heading-anchor" aria-hidden tabindex="-1" href="#server-code-text-image"><span class="anchor-icon">#</span></a>Server Code (Text + Image)</h3>
<pre><code class="hljs language-python"><span class="hljs-comment"># server_multimodal.py</span>

<span class="hljs-keyword">from</span> fastapi <span class="hljs-keyword">import</span> FastAPI, UploadFile, File, Form
<span class="hljs-keyword">from</span> transformers <span class="hljs-keyword">import</span> AutoProcessor, AutoModelForImageTextToText
<span class="hljs-keyword">from</span> PIL <span class="hljs-keyword">import</span> Image
<span class="hljs-keyword">import</span> torch
<span class="hljs-keyword">import</span> io

app = FastAPI()

model_id = <span class="hljs-string">"google/medgemma-4b-it"</span>

processor = AutoProcessor.from_pretrained(model_id)
model = AutoModelForImageTextToText.from_pretrained(
    model_id,
    torch_dtype=torch.float16
)
model.<span class="hljs-built_in">eval</span>()

<span class="hljs-meta">@app.post(<span class="hljs-params"><span class="hljs-string">"/chat"</span></span>)</span>
<span class="hljs-keyword">async</span> <span class="hljs-keyword">def</span> <span class="hljs-title function_">chat</span>(<span class="hljs-params">
    message: <span class="hljs-built_in">str</span> = Form(<span class="hljs-params">...</span>),
    image: UploadFile = File(<span class="hljs-params">...</span>)
</span>):

    <span class="hljs-comment"># Read binary image</span>
    image_bytes = <span class="hljs-keyword">await</span> image.read()

    <span class="hljs-comment"># Convert to PIL</span>
    pil_image = Image.<span class="hljs-built_in">open</span>(io.BytesIO(image_bytes)).convert(<span class="hljs-string">"RGB"</span>)

    messages = [{
        <span class="hljs-string">"role"</span>: <span class="hljs-string">"user"</span>,
        <span class="hljs-string">"content"</span>: [
            {<span class="hljs-string">"type"</span>: <span class="hljs-string">"text"</span>, <span class="hljs-string">"text"</span>: message},
            {<span class="hljs-string">"type"</span>: <span class="hljs-string">"image"</span>, <span class="hljs-string">"image"</span>: pil_image}
        ]
    }]

    inputs = processor.apply_chat_template(
        messages,
        add_generation_prompt=<span class="hljs-literal">True</span>,
        tokenize=<span class="hljs-literal">True</span>,
        return_tensors=<span class="hljs-string">"pt"</span>
    )

    <span class="hljs-keyword">with</span> torch.no_grad():
        output = model.generate(**inputs, max_new_tokens=<span class="hljs-number">200</span>)
    
    response = processor.decode(
        output[<span class="hljs-number">0</span>][inputs[<span class="hljs-string">"input_ids"</span>].shape[-<span class="hljs-number">1</span>]:],
        skip_special_tokens=<span class="hljs-literal">True</span>
    )
    <span class="hljs-keyword">return</span> {<span class="hljs-string">"response"</span>: response}
</code></pre>

<h3 id="server-code-text-only-gguf"><a class="heading-anchor" aria-hidden tabindex="-1" href="#server-code-text-only-gguf"><span class="anchor-icon">#</span></a>Server Code (Text-Only GGUF)</h3>
<pre><code class="hljs language-python"><span class="hljs-comment"># server_gguf_text.py</span>

    n_gpu_layers=<span class="hljs-number">0</span>

    <span class="hljs-keyword">return</span> {<span class="hljs-string">"response"</span>: response[<span class="hljs-string">"choices"</span>][<span class="hljs-number">0</span>][<span class="hljs-string">"message"</span>][<span class="hljs-string">"content"</span>]}

<h3 id="part-4fastapi--llama-cpp-multimodal-gguf-withmmproj"><a class="heading-anchor" aria-hidden tabindex="-1" href="#part-4fastapi--llama-cpp-multimodal-gguf-withmmproj"><span class="anchor-icon">#</span></a>Part 4 — FastAPI + llama-cpp (Multimodal GGUF with mmproj)</h3>

<h3 id="part-5using-llama-server-native-llamacpp-server"><a class="heading-anchor" aria-hidden tabindex="-1" href="#part-5using-llama-server-native-llamacpp-server"><span class="anchor-icon">#</span></a>Part 5 — Using llama-server (Native llama.cpp Server)</h3>
<blockquote>
<p>llama.cpp provides a built-in server.</p>
</blockquote>
<p>To use llama-server, you need to build llama.cpp from source to obtain the <em><strong>llama-server</strong></em> <strong>binary</strong>.</p>
<p><a href="https://medium.com/the-owl/%EF%B8%8F-how-to-start-using-llama-server-92aa6f81edc8">⚙️ How to Start Using llama-server</a></p>
<h3 id="run-textmodel"><a class="heading-anchor" aria-hidden tabindex="-1" href="#run-textmodel"><span class="anchor-icon">#</span></a>Run Text Model</h3>
<p><em><strong>If the model is downloaded locally</strong></em></p>
<pre><code class="hljs language-text">./llama-server \
  -m models/medgemma-4b-it-Q4_K_M.gguf \
  --port 8000
</code></pre>
<p><em><strong>If the model needs to be downloaded from HF</strong></em></p>
<pre><code class="hljs language-text">./llama-server \
--hf-repo unsloth/medgemma-4b-it-GGUF \
--hf-file medgemma-4b-it-Q4_K_M.gguf \
--port 8000
</code></pre>
<p>Then:</p>
<pre><code class="hljs language-bash">curl http://localhost:8000/v1/chat/completions \
-H <span class="hljs-string">"Content-Type: application/json"</span> \
-d <span class="hljs-string">'{"messages":[{"role":"user","content":"Explain pneumonia"}]}'</span>
</code></pre>
<h3 id="run-multimodal-model"><a class="heading-anchor" aria-hidden tabindex="-1" href="#run-multimodal-model"><span class="anchor-icon">#</span></a>Run Multimodal Model</h3>
<p><em><strong>Assuming the models are downloaded locally</strong></em></p>
<pre><code class="hljs language-text">./llama-server \
  -m models/medgemma-4b-it-Q4_K_M.gguf \
  --mmproj models/mmproj-medgemma-4b-it.gguf \
  --port 8000

# Automatically Download multimodal models

./llama-server \
--hf unsloth/medgemma-4b-it-GGUF \
--port 8000
</code></pre>
<p>Then:</p>
<pre><code class="hljs language-bash">curl http://localhost:8000/v1/chat/completions \
-d <span class="hljs-string">'{"messages": [{"role": "user","content": [{"type": "image_url","image_url": {"url": "https://upload.wikimedia.org/wikipedia/commons/c/c8/Chest_Xray_PA_3-8-2010.png"}},{"type": "text","text": "Describe this image in detail."}]}]}'</span>
</code></pre>
<p>If the model supports multimodal, you can input the media file via the image_url content part. <em><strong>llama-server</strong></em> supports both <strong>base64</strong> and <strong>remote URL</strong> as input.</p>
<p>The server internally parses the multipart and routes the image into the vision encoder.</p>
