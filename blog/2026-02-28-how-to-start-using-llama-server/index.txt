11:T25e9,<h4 id="you-must-build-llamacpp-first"><a class="heading-anchor" aria-hidden tabindex="-1" href="#you-must-build-llamacpp-first"><span class="anchor-icon">#</span></a>You Must Build llama.cpp first</h4>
<p><img src="/images/blog/how-to-start-using-llama-server/img1.png" alt=""></p>
<p>If you try to run:</p>
<pre><code class="hljs language-bash">./llama-server -m medgemma-4b-it-Q4_K_M.gguf --port 8000
</code></pre>
<p>And you see:</p>
<pre><code class="hljs language-bash">./llama-server: No such file or directory
</code></pre>
<p>That does <strong>not</strong> mean the model is missing.</p>
<p>It means:</p>
<blockquote>
<p><em>You have not built</em> <em>llama.cpp.</em></p>
</blockquote>
<p>Unlike the Python package llama-cpp-python, the llama-server executable is <strong>not pre-installed</strong> anywhere. It is part of the C++ repository and must be compiled.</p>
<h3 id="-why-this-step-isrequired"><a class="heading-anchor" aria-hidden tabindex="-1" href="#-why-this-step-isrequired"><span class="anchor-icon">#</span></a>🧠 Why This Step Is Required</h3>
<p>There are two different components that people often confuse:</p>
<pre><code class="hljs language-javascript">|      <span class="hljs-title class_">Component</span>    |     <span class="hljs-title class_">How</span> <span class="hljs-title class_">It</span>’s <span class="hljs-title class_">Installed</span>    |    <span class="hljs-title class_">What</span> <span class="hljs-title class_">It</span> <span class="hljs-title class_">Provides</span>   |  
| — — — — — — — — — | — — — — — — — — — — — — — | — — — — — — — — — — — |  
| <span class="hljs-string">`llama-cpp-python`</span>| <span class="hljs-string">`pip install`</span>             | <span class="hljs-title class_">Python</span> bindings       |  
| <span class="hljs-string">`llama.cpp`</span> (C++) | <span class="hljs-title class_">Must</span> be built <span class="hljs-keyword">from</span> source | <span class="hljs-string">`llama-server`</span> binary |
</code></pre>
<p>If you only installed:</p>
<pre><code class="hljs">pip install llama-cpp-python
</code></pre>
<p>You do <strong>not</strong> get:</p>
<pre><code class="hljs">llama-server
</code></pre>
<p>That executable only exists after building the C++ project.</p>
<h3 id="-building-llamacpp-fromscratch"><a class="heading-anchor" aria-hidden tabindex="-1" href="#-building-llamacpp-fromscratch"><span class="anchor-icon">#</span></a>🏗 Building llama.cpp from Scratch</h3>
<p>Below are the correct steps for Linux / macOS (including Colab).</p>
<h3 id="1️⃣-clone-the-repository"><a class="heading-anchor" aria-hidden tabindex="-1" href="#1️⃣-clone-the-repository"><span class="anchor-icon">#</span></a>1️⃣ Clone the Repository</h3>
<pre><code class="hljs language-bash">git <span class="hljs-built_in">clone</span> https://github.com/ggml-org/llama.cpp  
<span class="hljs-built_in">cd</span> llama.cpp
</code></pre>
<p>This downloads the source code.</p>
<h3 id="2️⃣-configure-thebuild"><a class="heading-anchor" aria-hidden tabindex="-1" href="#2️⃣-configure-thebuild"><span class="anchor-icon">#</span></a>2️⃣ Configure the Build</h3>
<p>If you want Hugging Face auto-download support (--hf-repo, --hf-file), you must enable CURL:</p>
<pre><code class="hljs language-ini">cmake -B build <span class="hljs-attr">-DGGML_CURL</span>=<span class="hljs-literal">ON</span>
</code></pre>
<p>If you want CUDA support (on GPU machines):</p>
<pre><code class="hljs language-ini">cmake -B build <span class="hljs-attr">-DGGML_CUDA</span>=<span class="hljs-literal">ON</span> -DGGML_CURL=<span class="hljs-literal">ON</span>
</code></pre>
<p>For Apple Silicon with Metal:</p>
<pre><code class="hljs language-ini">cmake -B build <span class="hljs-attr">-DGGML_METAL</span>=<span class="hljs-literal">ON</span> -DGGML_CURL=<span class="hljs-literal">ON</span>
</code></pre>
<h3 id="3️⃣-compile-theproject"><a class="heading-anchor" aria-hidden tabindex="-1" href="#3️⃣-compile-theproject"><span class="anchor-icon">#</span></a>3️⃣ Compile the Project</h3>
<pre><code class="hljs language-css">cmake <span class="hljs-attr">--build</span> build <span class="hljs-attr">--config</span> Release
</code></pre>
<p>After this completes, the binary will exist at:</p>
<pre><code class="hljs language-bash">build/bin/llama-server
</code></pre>
<p>Not in the root folder.</p>
<h3 id="-running-llama-server"><a class="heading-anchor" aria-hidden tabindex="-1" href="#-running-llama-server"><span class="anchor-icon">#</span></a>🚀 Running llama-server</h3>
<p>Now you can run:</p>
<pre><code class="hljs language-python">./build/<span class="hljs-built_in">bin</span>/llama-server \  
  --hf-repo unsloth/medgemma-4b-it-GGUF \  
  --hf-file medgemma-4b-it-Q4_K_M.gguf \  
  --port <span class="hljs-number">8000</span>  
  
<span class="hljs-comment"># Alternative way to run multimodal models  </span>
<span class="hljs-comment"># Automatically downloads mmproj model,   </span>
<span class="hljs-comment"># by default chooses Q4_K_M, or the first one if it is not present  </span>
./build/<span class="hljs-built_in">bin</span>/llama-server \  
  -hf unsloth/medgemma-4b-it-GGUF \  
  --port <span class="hljs-number">8000</span>
</code></pre>
<p>Or if models are local:</p>
<pre><code class="hljs language-bash">./build/bin/llama-server \  
  -m ./models/medgemma-4b-it-Q4_K_M.gguf \  
  --mmproj ./models/mmproj-BF16.gguf \  
  --port 8000
</code></pre>
<h3 id="-why-the-binary-is-in-buildbin"><a class="heading-anchor" aria-hidden tabindex="-1" href="#-why-the-binary-is-in-buildbin"><span class="anchor-icon">#</span></a>📁 Why the Binary Is in build/bin/</h3>
<p>llama.cpp uses CMake.<br>
CMake places compiled artefacts inside a build directory to:</p>
<ul>
<li>Separate source from compiled files</li>
<li>Allow multiple build configurations</li>
<li>Avoid polluting the repo</li>
</ul>
<p>That’s why:</p>
<pre><code class="hljs language-bash">./llama-server
</code></pre>
<p>doesn’t work. You must use:</p>
<pre><code class="hljs language-bash">./build/bin/llama-server
</code></pre>
<h3 id="-verifying-thebuild"><a class="heading-anchor" aria-hidden tabindex="-1" href="#-verifying-thebuild"><span class="anchor-icon">#</span></a>🔎 Verifying the Build</h3>
<p>To confirm it worked:</p>
<pre><code class="hljs language-bash"><span class="hljs-built_in">ls</span> build/bin
</code></pre>
<p>You should see:</p>
<pre><code class="hljs language-python-repl">llama-server  
llama-cli  
quantize  
<span class="hljs-meta prompt_">...</span>
</code></pre>
<p>If you don’t see llama-server, the build did not succeed.</p>
<h3 id="-how-to-make-llama-server-callableglobally"><a class="heading-anchor" aria-hidden tabindex="-1" href="#-how-to-make-llama-server-callableglobally"><span class="anchor-icon">#</span></a>✅ How To Make llama-server Callable Globally</h3>
<h3 id="option-1add-topath"><a class="heading-anchor" aria-hidden tabindex="-1" href="#option-1add-topath"><span class="anchor-icon">#</span></a>Option 1 — Add to PATH</h3>
<pre><code class="hljs language-ruby">export <span class="hljs-variable constant_">PATH</span>=<span class="hljs-variable">$PATH</span><span class="hljs-symbol">:/full/path/to/llama</span>.cpp/build/bin
</code></pre>
<p>Now you can run:</p>
<pre><code class="hljs">llama-server
</code></pre>
<h3 id="option-2create-asymlink"><a class="heading-anchor" aria-hidden tabindex="-1" href="#option-2create-asymlink"><span class="anchor-icon">#</span></a>Option 2 — Create a Symlink</h3>
<pre><code class="hljs language-swift">sudo ln <span class="hljs-operator">-</span>s <span class="hljs-regexp">/full/</span>path<span class="hljs-regexp">/to/</span>llama.cpp<span class="hljs-regexp">/build/</span>bin<span class="hljs-regexp">/llama-server /</span>usr<span class="hljs-regexp">/local/</span>bin<span class="hljs-operator">/</span>llama<span class="hljs-operator">-</span>server
</code></pre>
<p>Now it behaves like a system command.</p>
<h3 id="-important-enabling-hugging-facedownload"><a class="heading-anchor" aria-hidden tabindex="-1" href="#-important-enabling-hugging-facedownload"><span class="anchor-icon">#</span></a>🔐 Important: Enabling Hugging Face Download</h3>
<p>If you want to use:</p>
<pre><code class="hljs language-diff"><span class="hljs-deletion">--hf-repo  </span>
<span class="hljs-deletion">--hf-file  </span>
  
# or  
  
<span class="hljs-deletion">-hf</span>
</code></pre>
<p>You must compile with:</p>
<pre><code class="hljs language-ini"><span class="hljs-attr">-DGGML_CURL</span>=<span class="hljs-literal">ON</span>
</code></pre>
<p>Otherwise, the flags will exist, but downloading will fail.</p>
<h3 id="-finaltakeaway"><a class="heading-anchor" aria-hidden tabindex="-1" href="#-finaltakeaway"><span class="anchor-icon">#</span></a>🧠 Final Takeaway</h3>
<p>llama-server is not a pip tool.</p>
<p>It is a compiled C++ executable.</p>
<p>Before using it, you must:</p>
<ol>
<li>Clone llama.cpp</li>
<li>Configure CMake</li>
<li>Build the project</li>
<li>Run the binary from build/bin/</li>
</ol>
