<p>In this article, we will learn how to plot multiple 2D series data in a single 3D plot like the one shown below!!</p>
<p><img src="/images/blog/how-to-plot-multiple-2d-series-in-3d-waterfall-plot-in-matpl/img1.png" alt=""></p>
<blockquote>
<p>Step 1: Importing required libraries (or only a few objects)</p>
</blockquote>
<pre><code class="hljs language-python"><span class="hljs-keyword">from</span> mpl_toolkits.mplot3d <span class="hljs-keyword">import</span> Axes3D
<span class="hljs-keyword">import</span> numpy <span class="hljs-keyword">as</span> np
<span class="hljs-keyword">import</span> matplotlib.pyplot <span class="hljs-keyword">as</span> plt
</code></pre>
<blockquote>
<p>Step 2: Defining a figure and axis</p>
</blockquote>
<pre><code class="hljs language-text">fig = plt.figure()
ax = fig.add_subplot(projection=’3d’)
</code></pre>
<blockquote>
<p>Step 3: Getting some data</p>
</blockquote>
<pre><code class="hljs language-text"># Plot a sin curve using the x and y axes.
for z in range(0, 50, 5):
    x = np.linspace(0, 1, 100)
    y = z*np.sin(x * 2 * np.pi) / 50 / 2 + 0.5
    plot2din3d(x, y, z)
</code></pre>
<blockquote>
<p>Step 4: plot2din3d()</p>
</blockquote>
<pre><code class="hljs language-python"><span class="hljs-keyword">def</span> <span class="hljs-title function_">plot2din3d</span>(<span class="hljs-params">x,y,z</span>):
    ax.plot(x, y, zs=z, zdir=<span class="hljs-string">'z'</span>)
    2d_col_obj = ax.fill_between(x, <span class="hljs-number">0.5</span>, y, step=<span class="hljs-string">'pre'</span>, alpha=<span class="hljs-number">0.1</span>) 
    ax.add_collection3d(2d_col_obj, zs = z, zdir = <span class="hljs-string">'z'</span>)
</code></pre>
<blockquote>
<p>Step 5: Set Legend, set axes limits and labels</p>
</blockquote>
<pre><code class="hljs language-text">#ax.legend()
ax.set_xlim(0, 1)
ax.set_ylim(0, 1)
ax.set_zlim(0, 50)
ax.set_xlabel(‘X’)
ax.set_ylabel(‘Y’)
ax.set_zlabel(‘Z’)
</code></pre>
<blockquote>
<p>Step 6: Customizing View Angle</p>
</blockquote>
<pre><code class="hljs language-text">ax.view_init(elev=20., azim=-35)
</code></pre>
<blockquote>
<p>Step 7: Plot the plot</p>
</blockquote>
<pre><code class="hljs language-text">plt.show()
</code></pre>
<blockquote>
<p>Final Result</p>
</blockquote>
<p><img src="/images/blog/how-to-plot-multiple-2d-series-in-3d-waterfall-plot-in-matpl/img2.png" alt=""></p>
<p><strong>We can do this for any type of series data!!</strong></p>
<h4 id="the-data-above-was-however-dense-hence-looks-continuous"><a class="heading-anchor" aria-hidden tabindex="-1" href="#the-data-above-was-however-dense-hence-looks-continuous"><span class="anchor-icon">#</span></a>The data above was, however, dense. Hence, looks continuous.</h4>
<h3 id="how-about-discrete-data-not-so-denselyspaced"><a class="heading-anchor" aria-hidden tabindex="-1" href="#how-about-discrete-data-not-so-denselyspaced"><span class="anchor-icon">#</span></a>How about discrete data, not so densely spaced?</h3>
<blockquote>
<p>Let us, set some values to some variables, which we can tweak to obtain different plots!!</p>
</blockquote>
<pre><code class="hljs language-text">num_samples = 10
num_series = 3
minx, maxx = 0, 10
res = 100
zmin, zmax = 0, 60
zinterval = 20
</code></pre>
<blockquote>
<p>Next,</p>
</blockquote>
<pre><code class="hljs language-text">y = np.random.random((num_series,num_samples))
</code></pre>
<pre><code class="hljs language-text">x = np.linspace(minx, maxx, num_samples)
</code></pre>
<pre><code class="hljs language-text">z_idx_range = int((zmax-zmin)/zinterval)
</code></pre>
<pre><code class="hljs language-text">colors = plt.cm.get_cmap(‘inferno’,z_idx_range)
</code></pre>
<blockquote>
<p>Next, we interpolate points between the samples data points, to get a continuous looking plot!!</p>
</blockquote>
<pre><code class="hljs language-text">for i in range(z_idx_range):
    z = zinterval*i + zmin
    yz, ys, ye = y[i,:], None, None
    ynew_ = np.array([])
    for j in range(y.shape[1]-1):
        ys = y[i,j]
        ye = y[i,j+1]
        ynew_ = np.append(ynew_, np.linspace(ys, ye, res), axis = 0)
</code></pre>
<pre><code class="hljs language-text">    xz = np.linspace(minx, maxx, (y.shape[1]-1)*res)
    plot2din3d_discrete(xz,x,ynew_,yz,z,colors(i))
</code></pre>
<blockquote>
<p>plot2din3d_discrete()</p>
</blockquote>
<pre><code class="hljs language-python"><span class="hljs-keyword">def</span> <span class="hljs-title function_">plot2din3d_discrete</span>(<span class="hljs-params">x,xo,y,yo,z,c</span>):
    ax.plot(xo, yo,’o’,color=c,zs=z, zdir=’z’)
    ax.plot(x, y, color=c,zs=z, zdir=’z’)
    <span class="hljs-comment"># Add a 3D collection object to the plot.</span>
    2d_col_obj = ax.fill_between(x, <span class="hljs-number">0.0</span>, y, step=<span class="hljs-string">'mid'</span>, alpha=<span class="hljs-number">0.3</span>)       
    ax.add_collection3d(2d_col_obj, zs = z)
</code></pre>
