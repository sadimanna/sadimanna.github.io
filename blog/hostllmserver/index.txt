<p>Running a Large Language Model locally on your laptop is great for testing, but it’s a long way from building a usable product. To turn an LLM into an actual service—whether for a mobile app, web platform, or internal workflow—you need to serve it over HTTP. That means properly handling incoming requests, parsing JSON and multipart/form-data, managing binary uploads like images, and returning clean structured responses.</p>
<p>In this article, we’ll step through building production-style server setups for both text-only and multimodal LLMs. We'll explore three distinct backend strategies—FastAPI with Hugging Face Transformers, FastAPI with llama-cpp-python (GGUF), and native llama-server—so you can pick the exact right stack for your deployment requirements.</p>
<p>If you want to build real applications, you must learn how to:</p>
<ul>
<li>Accept HTTP requests</li>
<li>Parse JSON and multipart form data</li>
<li>Handle binary file uploads</li>
<li>Forward inputs to an LLM</li>
<li>Return structured responses</li>
</ul>
<p>In this tutorial, we’ll build production-style servers for:</p>
<ol>
<li><strong>Text-only LLM</strong></li>
<li><strong>Multimodal LLM (text + image)</strong></li>
</ol>
<p>We’ll implement this in two ways:</p>
<ul>
<li>✅ Using <strong>FastAPI + Transformers</strong></li>
<li>✅ Using <strong>FastAPI + llama-cpp (GGUF)</strong></li>
<li>✅ Using <strong>llama-server (native llama.cpp
server)</strong></li>
</ul>
<p>All examples follow proper <code>multipart/form-data</code> format for file
uploads.</p>
<h2 id="architecture-overview"><a class="heading-anchor" aria-hidden tabindex="-1" href="#architecture-overview"><span class="anchor-icon">#</span></a>Architecture Overview</h2>
<pre><code class="hljs language-bash">Client (curl / browser / app)
        ↓
HTTP Request (JSON or multipart)
        ↓
FastAPI or llama-server
        ↓
LLM (Transformers or GGUF)
        ↓
Response
</code></pre>
<h2 id="part-1--fastapi--transformers-text-only-llm"><a class="heading-anchor" aria-hidden tabindex="-1" href="#part-1--fastapi--transformers-text-only-llm"><span class="anchor-icon">#</span></a>Part 1 — FastAPI + Transformers (Text-Only LLM)</h2>
<p>We’ll start with a text-only model.</p>
<h2 id="install"><a class="heading-anchor" aria-hidden tabindex="-1" href="#install"><span class="anchor-icon">#</span></a>Install</h2>
<pre><code class="hljs language-bash">pip install fastapi uvicorn transformers torch
</code></pre>
<h2 id="server-code-text-only"><a class="heading-anchor" aria-hidden tabindex="-1" href="#server-code-text-only"><span class="anchor-icon">#</span></a>Server Code (Text-Only)</h2>
<pre><code class="hljs language-bash"><span class="hljs-comment"># server_text.py</span>
from fastapi import FastAPI
from pydantic import BaseModel
from transformers import AutoTokenizer, AutoModelForCausalLM
import torch

app = FastAPI()

model_id = <span class="hljs-string">"openai-community/gpt2"</span>

tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModelForCausalLM.from_pretrained(model_id)
model.eval()

class ChatRequest(BaseModel):
    message: str

@app.post(<span class="hljs-string">"/chat"</span>)
async def chat(req: ChatRequest):
    inputs = tokenizer(req.message, return_tensors=<span class="hljs-string">"pt"</span>)

    with torch.no_grad():
        output = model.generate(**inputs, max_new_tokens=100)
    
    response = tokenizer.decode(output[0], skip_special_tokens=True)

    <span class="hljs-built_in">return</span> {<span class="hljs-string">"response"</span>: response}
</code></pre>

<p>We must use <code>multipart/form-data</code> because we are sending binary images.</p>
<h2 id="install-1"><a class="heading-anchor" aria-hidden tabindex="-1" href="#install-1"><span class="anchor-icon">#</span></a>Install</h2>

<h2 id="server-code-text--image"><a class="heading-anchor" aria-hidden tabindex="-1" href="#server-code-text--image"><span class="anchor-icon">#</span></a>Server Code (Text + Image)</h2>
<pre><code class="hljs language-bash"><span class="hljs-comment"># server_multimodal.py</span>

from fastapi import FastAPI, UploadFile, File, Form
from transformers import AutoProcessor, AutoModelForImageTextToText
from PIL import Image
import torch
import io

app = FastAPI()

model_id = <span class="hljs-string">"google/medgemma-4b-it"</span>

processor = AutoProcessor.from_pretrained(model_id)
model = AutoModelForImageTextToText.from_pretrained(
    model_id,
    torch_dtype=torch.float16
)
model.eval()

@app.post(<span class="hljs-string">"/chat"</span>)
async def chat(
    message: str = Form(...),
    image: UploadFile = File(...)
):

    <span class="hljs-comment"># Read binary image</span>
    image_bytes = await image.read()

    <span class="hljs-comment"># Convert to PIL</span>
    pil_image = Image.open(io.BytesIO(image_bytes)).convert(<span class="hljs-string">"RGB"</span>)

    messages = [{
        <span class="hljs-string">"role"</span>: <span class="hljs-string">"user"</span>,
        <span class="hljs-string">"content"</span>: [
            {<span class="hljs-string">"type"</span>: <span class="hljs-string">"text"</span>, <span class="hljs-string">"text"</span>: message},
            {<span class="hljs-string">"type"</span>: <span class="hljs-string">"image"</span>, <span class="hljs-string">"image"</span>: pil_image}
        ]
    }]

    inputs = processor.apply_chat_template(
        messages,
        add_generation_prompt=True,
        tokenize=True,
        return_tensors=<span class="hljs-string">"pt"</span>
    )

    with torch.no_grad():
        output = model.generate(**inputs, max_new_tokens=200)
    
    response = processor.decode(
        output[0][inputs[<span class="hljs-string">"input_ids"</span>].shape[-1]:],
        skip_special_tokens=True
    )
    <span class="hljs-built_in">return</span> {<span class="hljs-string">"response"</span>: response}
</code></pre>

<h2 id="part-3--fastapi--llama-cpp-gguf-text-model"><a class="heading-anchor" aria-hidden tabindex="-1" href="#part-3--fastapi--llama-cpp-gguf-text-model"><span class="anchor-icon">#</span></a>Part 3 — FastAPI + llama-cpp (GGUF Text Model)</h2>
<p><strong>GGUF</strong> models run through <em><strong>llama-cpp</strong></em>, which is a <em><strong>C++</strong></em>

<h2 id="install-cpu"><a class="heading-anchor" aria-hidden tabindex="-1" href="#install-cpu"><span class="anchor-icon">#</span></a>Install (CPU)</h2>

</code></pre>
<p>For GPU (CUDA):</p>
<pre><code class="hljs language-bash">CMAKE_ARGS=<span class="hljs-string">"-DGGML_CUBLAS=on"</span> pip install llama-cpp-python --no-cache-dir
</code></pre>
<h2 id="server-code-text-only-gguf"><a class="heading-anchor" aria-hidden tabindex="-1" href="#server-code-text-only-gguf"><span class="anchor-icon">#</span></a>Server Code (Text-Only GGUF)</h2>
<pre><code class="hljs language-bash"><span class="hljs-comment"># server_gguf_text.py</span>
from fastapi import FastAPI
from pydantic import BaseModel
from llama_cpp import Llama

app = FastAPI()

model = Llama.from_pretrained(
    repo_id=<span class="hljs-string">"unsloth/medgemma-4b-it-GGUF"</span>,
    filename=<span class="hljs-string">"medgemma-4b-it-Q4_K_M.gguf"</span>,
    n_gpu_layers=0
)

class ChatRequest(BaseModel):
    message: str

@app.post(<span class="hljs-string">"/chat"</span>)
async def chat(req: ChatRequest):
    response = model.create_chat_completion(
        messages=[
            {<span class="hljs-string">"role"</span>: <span class="hljs-string">"user"</span>, <span class="hljs-string">"content"</span>: req.message}
        ],
        max_tokens=200
    )
    <span class="hljs-built_in">return</span> {<span class="hljs-string">"response"</span>: response[<span class="hljs-string">"choices"</span>][0][<span class="hljs-string">"message"</span>][<span class="hljs-string">"content"</span>]}
</code></pre>
<h2 id="part-4--fastapi--llama-cpp-multimodal-gguf-with-mmproj"><a class="heading-anchor" aria-hidden tabindex="-1" href="#part-4--fastapi--llama-cpp-multimodal-gguf-with-mmproj"><span class="anchor-icon">#</span></a>Part 4 — FastAPI + llama-cpp (Multimodal GGUF with mmproj)</h2>
<p>Multimodal GGUF models require:</p>
<ul>
<li>Main model <strong>GGUF</strong></li>
<li><strong>mmproj</strong> file (vision projection weights)</li>
</ul>

<span class="hljs-comment"># ---------------------------------------------------------</span>
<span class="hljs-comment"># Load Multimodal GGUF Model Properly</span>
<span class="hljs-comment"># ---------------------------------------------------------</span>

<span class="hljs-comment"># Load vision projection (mmproj) from HF</span>

<span class="hljs-comment">#             n_gpu_layers=0</span>
<span class="hljs-comment"># )</span>

<span class="hljs-comment"># Load model from HF</span>

    repo_id=<span class="hljs-string">"unsloth/medgemma-4b-it-GGUF"</span>,

and <strong>remote URL</strong> as input.</p>
<p>The server internally parses the multipart and routes the image into the
vision encoder.</p>
