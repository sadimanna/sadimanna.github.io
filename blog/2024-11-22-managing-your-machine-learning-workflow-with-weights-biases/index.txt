<p>Weights &#x26; Biases (W&#x26;B) offers a powerful feature called Artifacts, which allows you to version and track datasets, models, and other files crucial to your machine learning workflow. In this blog post, we’ll explore how to use W&#x26;B Artifacts to save and manage various types of files.</p>
<h3 id="prerequisites"><a class="heading-anchor" aria-hidden tabindex="-1" href="#prerequisites"><span class="anchor-icon">#</span></a>Prerequisites</h3>
<p>Before we dive in, make sure you have W&#x26;B installed. You can install it using pip:</p>
<pre><code class="hljs language-bash">pip install wandb
</code></pre>
<h3 id="1-savingdatasets"><a class="heading-anchor" aria-hidden tabindex="-1" href="#1-savingdatasets"><span class="anchor-icon">#</span></a>1. Saving Datasets</h3>
<p>You can save datasets as artifacts to ensure that the exact versions used in your experiments are tracked and reproducible.</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> wandb  
<span class="hljs-comment"># Initialize a new run </span>
wandb.init(project=<span class="hljs-string">"your-project-name"</span>, name=<span class="hljs-string">"your-run-name"</span>)  
<span class="hljs-comment"># Create an artifact for the dataset </span>
dataset_artifact = wandb.Artifact(<span class="hljs-string">'dataset-name'</span>, <span class="hljs-built_in">type</span>=<span class="hljs-string">'dataset'</span>)  
<span class="hljs-comment"># Add the dataset files or directories to the artifact </span>
dataset_artifact.add_file(<span class="hljs-string">'path/to/your/dataset.csv'</span>) 
<span class="hljs-comment"># or </span>
dataset_artifact.add_dir(<span class="hljs-string">'path/to/your/dataset-directory'</span>)  
<span class="hljs-comment"># Log the artifact </span>
wandb.log_artifact(dataset_artifact)
</code></pre>
<h3 id="2-savingmodels"><a class="heading-anchor" aria-hidden tabindex="-1" href="#2-savingmodels"><span class="anchor-icon">#</span></a>2. Saving Models</h3>
<p>You can save trained models as artifacts to keep track of different versions and enable easy retrieval for inference or further training.</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> wandb  
<span class="hljs-comment"># Initialize a new run </span>
wandb.init(project=<span class="hljs-string">"your-project-name"</span>, name=<span class="hljs-string">"your-run-name"</span>)  
<span class="hljs-comment"># Train your model and save it </span>
model.save(<span class="hljs-string">'path/to/your/model.h5'</span>)  
<span class="hljs-comment"># Create an artifact for the model </span>
model_artifact = wandb.Artifact(<span class="hljs-string">'model-name'</span>, <span class="hljs-built_in">type</span>=<span class="hljs-string">'model'</span>)  
<span class="hljs-comment"># Add the model file to the artifact </span>
model_artifact.add_file(<span class="hljs-string">'path/to/your/model.h5'</span>)  
<span class="hljs-comment"># Log the artifact </span>
wandb.log_artifact(model_artifact)
</code></pre>
<h3 id="3-saving-intermediate-results"><a class="heading-anchor" aria-hidden tabindex="-1" href="#3-saving-intermediate-results"><span class="anchor-icon">#</span></a>3. Saving Intermediate Results</h3>
<p>Intermediate results, such as preprocessed data, feature sets, or intermediate model checkpoints, can be saved as artifacts.</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> wandb  
<span class="hljs-comment"># Initialize a new run </span>
wandb.init(project=<span class="hljs-string">"your-project-name"</span>, name=<span class="hljs-string">"your-run-name"</span>)  
<span class="hljs-comment"># Save intermediate results </span>
preprocessed_data.to_csv(<span class="hljs-string">'path/to/preprocessed_data.csv'</span>)  
<span class="hljs-comment"># Create an artifact for the intermediate results </span>
intermediate_artifact = wandb.Artifact(<span class="hljs-string">'preprocessed-data'</span>, <span class="hljs-built_in">type</span>=<span class="hljs-string">'preprocessed-data'</span>)  <span class="hljs-comment"># Add the intermediate result file to the artifact </span>
intermediate_artifact.add_file(<span class="hljs-string">'path/to/preprocessed_data.csv'</span>) 
<span class="hljs-comment"># Log the artifact </span>
wandb.log_artifact(intermediate_artifact)
</code></pre>
<h3 id="4-saving-configuration-files"><a class="heading-anchor" aria-hidden tabindex="-1" href="#4-saving-configuration-files"><span class="anchor-icon">#</span></a>4. Saving Configuration Files</h3>
<p>You can save configuration files, such as YAML or JSON files, that contain hyperparameters or other settings used in your experiments.</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> wandb  
<span class="hljs-comment"># Initialize a new run </span>
wandb.init(project=<span class="hljs-string">"your-project-name"</span>, name=<span class="hljs-string">"your-run-name"</span>)  
<span class="hljs-comment"># Create an artifact for the configuration file </span>
config_artifact = wandb.Artifact(<span class="hljs-string">'config'</span>, <span class="hljs-built_in">type</span>=<span class="hljs-string">'config'</span>)  
<span class="hljs-comment"># Add the configuration file to the artifact </span>
config_artifact.add_file(<span class="hljs-string">'path/to/your/config.yaml'</span>)  
<span class="hljs-comment"># Log the artifact </span>
wandb.log_artifact(config_artifact)
</code></pre>
<h3 id="5-saving-customobjects"><a class="heading-anchor" aria-hidden tabindex="-1" href="#5-saving-customobjects"><span class="anchor-icon">#</span></a>5. Saving Custom Objects</h3>
<p>You can save any custom objects or files that are important for your experiments, such as custom scripts, evaluation results, or visualizations.</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> wandb  
<span class="hljs-comment"># Initialize a new run </span>
wandb.init(project=<span class="hljs-string">"your-project-name"</span>, name=<span class="hljs-string">"your-run-name"</span>)  
<span class="hljs-comment"># Save custom objects </span>
<span class="hljs-keyword">with</span> <span class="hljs-built_in">open</span>(<span class="hljs-string">'path/to/custom_object.pkl'</span>, <span class="hljs-string">'wb'</span>) <span class="hljs-keyword">as</span> f:     
    pickle.dump(custom_object, f)  
<span class="hljs-comment"># Create an artifact for the custom object </span>
custom_object_artifact = wandb.Artifact(<span class="hljs-string">'custom-object'</span>, <span class="hljs-built_in">type</span>=<span class="hljs-string">'custom'</span>)  
<span class="hljs-comment"># Add the custom object file to the artifact </span>
custom_object_artifact.add_file(<span class="hljs-string">'path/to/custom_object.pkl'</span>)  
<span class="hljs-comment"># Log the artifact </span>
wandb.log_artifact(custom_object_artifact)
</code></pre>
<h3 id="6-saving-sourcecode"><a class="heading-anchor" aria-hidden tabindex="-1" href="#6-saving-sourcecode"><span class="anchor-icon">#</span></a>6. Saving Source Code</h3>
<p>You can save your source code as an artifact to ensure reproducibility.</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> wandb  
<span class="hljs-comment"># Initialize a new run</span>
wandb.init(project=<span class="hljs-string">"your-project-name"</span>, name=<span class="hljs-string">"your-run-name"</span>)  
<span class="hljs-comment"># Create an artifact for the source code </span>
code_artifact = wandb.Artifact(<span class="hljs-string">'source-code'</span>, <span class="hljs-built_in">type</span>=<span class="hljs-string">'code'</span>)  
<span class="hljs-comment"># Add the source code files or directory to the artifact </span>
code_artifact.add_dir(<span class="hljs-string">'path/to/your/source/code'</span>)  
<span class="hljs-comment"># Log the artifact </span>
wandb.log_artifact(code_artifact)
</code></pre>
<h3 id="example-using-artifacts-for-dataset-andmodel"><a class="heading-anchor" aria-hidden tabindex="-1" href="#example-using-artifacts-for-dataset-andmodel"><span class="anchor-icon">#</span></a>Example: Using Artifacts for Dataset and Model</h3>
<p>Here’s a complete example that shows how to use artifacts for saving both a dataset and a trained model.</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> wandb  
<span class="hljs-comment"># Initialize a new run </span>
wandb.init(project=<span class="hljs-string">"your-project-name"</span>, name=<span class="hljs-string">"your-run-name"</span>)  
<span class="hljs-comment"># Dataset Artifact </span>
dataset_artifact = wandb.Artifact(<span class="hljs-string">'dataset'</span>, <span class="hljs-built_in">type</span>=<span class="hljs-string">'dataset'</span>) 
dataset_artifact.add_file(<span class="hljs-string">'path/to/dataset.csv'</span>) 
wandb.log_artifact(dataset_artifact)  
<span class="hljs-comment"># Train your model </span>
model = train_model(...)  
<span class="hljs-comment"># Save the trained model </span>
model.save(<span class="hljs-string">'path/to/model.h5'</span>)  
<span class="hljs-comment"># Model Artifact </span>
model_artifact = wandb.Artifact(<span class="hljs-string">'trained-model'</span>, <span class="hljs-built_in">type</span>=<span class="hljs-string">'model'</span>) 
model_artifact.add_file(<span class="hljs-string">'path/to/model.h5'</span>) 
wandb.log_artifact(model_artifact)
</code></pre>
<p>By using W&#x26;B Artifacts, you can ensure that all important files and objects in your machine learning workflow are versioned, tracked, and easily accessible, enabling better reproducibility and collaboration.</p>
