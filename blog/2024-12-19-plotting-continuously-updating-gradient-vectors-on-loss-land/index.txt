<h2 id="mathematical-formulation-of-gradient-vectors"><a class="heading-anchor" aria-hidden tabindex="-1" href="#mathematical-formulation-of-gradient-vectors"><span class="anchor-icon">#</span></a>Mathematical Formulation of Gradient Vectors</h2>
<p>In deep learning, <strong>it is important to visualize the processes that happen beneath the multiple layers of abstraction to fully grasp the complex nature of the optimization in the non-convex loss landscape</strong>. In my attempt at such an endeavour, the approach that I often use is to visualize the million-dimensional parameter space in terms of a 3D space with 2 independent dimensions representing two parameters of the model and the dependent dimension representing the loss. <em>However, plotting the loss landscape can be a tough job as it is not possible to evaluate the loss surface for all points in the million-dimensional parameter space.</em></p>
<p>In this article, we will learn to plot gradient vectors in the 2D plane. As the gradients are just vectors, we can represent them using a magnitude (<em><strong>lg</strong></em>) and an angle.</p>
<p><img src="/images/blog/plotting-continuously-updating-gradient-vectors-on-loss-land/img2.png" alt=""></p>
<p>Magnitude and angle with each axis</p>
<p>Based on the above equation, we can calculate the new position,</p>
<p><img src="/images/blog/plotting-continuously-updating-gradient-vectors-on-loss-land/img3.png" alt=""></p>
<p>New position of the parameter along x-axis</p>
<p><img src="/images/blog/plotting-continuously-updating-gradient-vectors-on-loss-land/img4.png" alt=""></p>
<p>New position of the parameter along y-axis</p>
<p>So, at each step of plotting, we need to plot a line from the point in the parameter space at time <em><strong>t</strong></em> to the point at time <em><strong>t+1</strong></em>. While we can calculate the length of the gradient easily, the gradient vectors make an angle with each dimensional axis. Suppose, we take the 2 parameters with the largest gradient magnitudes along their respective axes.</p>
<h2 id="python-implementation-with-matplotlib"><a class="heading-anchor" aria-hidden tabindex="-1" href="#python-implementation-with-matplotlib"><span class="anchor-icon">#</span></a>Python Implementation with Matplotlib</h2>
<p>The ultimate goal is to visualize the continuous change in the parameter values in the same plot. So, let’s take a look at the code:</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> numpy <span class="hljs-keyword">as</span> np
<span class="hljs-keyword">import</span> matplotlib.pyplot <span class="hljs-keyword">as</span> plt
<span class="hljs-keyword">import</span> time
</code></pre>
<pre><code class="hljs language-text">if __name__=='__main__':
    x = np.array([0])
    y = np.array([0])
    ####### Matplotlib Interactive mode 
    plt.ion()
    ########### Sub plots ############
    figure, ax = plt.subplots(figsize=(10, 8))
    line1, = ax.plot(x, y)
    ############ Title ###############
    plt.title(“Vectors”, fontsize=20)
    # setting x-axis label and y-axis label
    plt.xlabel(r”$w_1$”)
    plt.ylabel(r”$w_2$”)
    ###### Append new values and plotting
    for _ in range(50):
        # creating new Y values
        length = np.random.random()
        angle = np.pi*(2*np.random.random()-1)
        x_t = x[-1] + length*np.cos(angle)
        y_t = y[-1] + length*np.sin(angle)
        x = np.append(x, x_t)
        y = np.append(y, y_t)
        # updating data values
        line1.set_xdata(x)
        line1.set_ydata(y)
        plt.xlim([x.min()-1, x.max()+1])
        plt.ylim([y.min()-1, y.max()+1])
        # drawing updated values
        figure.canvas.draw()
        # This will run the GUI event loop until all 
        # UI events currently waiting have been processed
        figure.canvas.flush_events()
        ####### time delay
        time.sleep(0.1)
    plt.ioff()
    plt.show()
    plt.savefig('./vectors.png')
</code></pre>
<p>This code takes a random length of the gradient, and we use the equations above to calculate <em><strong>gx</strong></em> and <em><strong>gy</strong></em>. However, in a real experimental run, we would have the values of <em><strong>gx</strong></em> and <em><strong>gy</strong></em>.</p>
<h2 id="interactive-window-configuration--troubleshooting"><a class="heading-anchor" aria-hidden tabindex="-1" href="#interactive-window-configuration--troubleshooting"><span class="anchor-icon">#</span></a>Interactive Window Configuration &#x26; Troubleshooting</h2>
<p>However, this step may throw the error</p>
<blockquote>
<p>“<em><strong>UserWarning: FigureCanvasAgg is non-interactive, and thus cannot be shown plt.show()</strong></em>”.</p>
</blockquote>
<p>This will require installing PyQt5.</p>
<pre><code class="hljs language-text">python3 -m pip install PyQt5
</code></pre>
<p>After this step, another error may still occur, that is,</p>
<blockquote>
<p><em><strong>qt.qpa.plugin: Could not find the Qt platform plugin “wayland” in “”</strong></em>.</p>
</blockquote>
<p>This can be solved by installing <strong>qtwayland5,</strong> using</p>
<pre><code class="hljs language-bash"><span class="hljs-built_in">sudo</span> apt install qtwayland5
</code></pre>
<p>followed by setting the environment variable <strong>QT_QPA_PLATFORM</strong> to <strong>xcb</strong>, using the command</p>
<pre><code class="hljs language-text">export QT_QPA_PLATFORM=xcb
</code></pre>
<p>To keep the plot from closing, it is important to add the following lines at the end</p>
<pre><code class="hljs language-text">plt.ioff()
plt.show()
</code></pre>
