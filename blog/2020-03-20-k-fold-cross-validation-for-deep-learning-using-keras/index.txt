<p>Machine Learning models often fails to generalize well on data it has not been trained on. Sometimes, it fails miserably, sometimes it gives somewhat better than miserable performance. To be sure that the model can perform well on unseen data, we use a re-sampling technique, called <strong>Cross-Validation</strong>.</p>
<p>We often follow a simple approach of splitting the data into 3 parts, namely, <em><strong>Train</strong></em>, <em><strong>Validation</strong></em> and <em><strong>Test</strong></em> sets. But this technique does not generally work well for cases when we don’t have a large datasets. When we have limited data, dividing the dataset into Train and Validation sets may casue some data points with useful information to be excluded from the training procedure, and the model fails to learn the data distrubution properly.</p>
<h2 id="what-is-k-fold-cross-validation"><a class="heading-anchor" aria-hidden tabindex="-1" href="#what-is-k-fold-cross-validation"><span class="anchor-icon">#</span></a>What is K-Fold Cross Validation?</h2>
<p><img src="/images/blog/k-fold-cross-validation-for-deep-learning-using-keras/img1.png" alt=""></p>
<p>K-Fold CV gives a model with less bias compared to other methods. In K-Fold CV, we have a paprameter ‘<em><strong>k</strong></em>’. This parameter decides how many folds the dataset is going to be divided. Every fold gets chance to appears in the training set (<em><strong>k-1</strong></em>) times, which in turn ensures that every observation in the dataset appears in the dataset, thus enabling the model to learn the underlying data distribution better.</p>
<p>The value of ‘<em><strong>k</strong></em>’ used is generally between 5 or 10. The value of ‘<em><strong>k</strong></em>’ should not be too low or too high. If the value of ‘<em><strong>k</strong></em>’ is too low (say <em><strong>k</strong></em> = 2), we will have a highly biased model. This case is similar to that of splitting the dataset into training and validation sets, hence the bias will be high and variance low. If the value of ‘<em><strong>k</strong></em>’ is large (say <em><strong>k</strong></em> = <em><strong>n</strong></em> (the number of observations)), then this approach is called <strong>Leave One Out CV</strong> (<strong>LOOCV</strong>). In this case, bias will be low but the variance will be high and the model will overfit, resulting in the model to fail in generalizing over the test set.</p>
<p>Another approach is to shuffle the dataset just once prior to splitting the dataset into <em><strong>k</strong></em> folds, and then split, such that the <strong>ratio</strong> of the observations in each class remains the same in each fold. Also the test set does not overlap between consecutive iterations. This approach is called <em><strong>Stratified K-Fold CV</strong></em>. This approach is useful for imbalanced datasets.</p>

<p>Importing Required Libraries</p>
<p>Here, we are assuming that all the images in Train set are in the folder <em><strong>train</strong></em> and the labels of corresponding image files are in a csv file, say <em><strong>training_labels.csv</strong></em>, which has two columns, <em><strong>filename</strong></em> and <em><strong>label</strong></em>.</p>
<p><img src="/images/blog/k-fold-cross-validation-for-deep-learning-using-keras/img3.jpeg" alt=""></p>
<p>Sample image for training_labels.csv</p>
<p>The column <em><strong>filename</strong></em> either contains only the name of the image file or the whole path to the image file. In case it does not contain the whole file path, otherwise we have to pass the path to the directory in which the images are stored as the <em><strong>directory</strong></em> argument. If one wants to use the method <em><strong>flow_from_directory</strong></em>, then one have to move image files in and out of the folders for each class for any two of the <em><strong>k</strong></em> folds, <em><strong>k</strong></em> number of times, since this method requires the images belonging to one class are present in respective folders under a single master directory. Hence, we can add the path to the image file names, in the csv files.</p>
