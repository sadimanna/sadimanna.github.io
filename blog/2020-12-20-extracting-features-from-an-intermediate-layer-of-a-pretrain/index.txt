<h4 id="initialize-the-pre-trained-model"><a class="heading-anchor" aria-hidden tabindex="-1" href="#initialize-the-pre-trained-model"><span class="anchor-icon">#</span></a>Initialize the Pre-trained model</h4>

<p>To make a feature extractor with the pre-trained ResNet-18, we modify this OrderedDict and make a Sequential model using <strong>nn.Sequential.</strong></p>
<h3 id="how-to-doit"><a class="heading-anchor" aria-hidden tabindex="-1" href="#how-to-doit"><span class="anchor-icon">#</span></a><strong>How to do it?</strong></h3>
<p>In this code snippet, we take the <strong>OrderedDict</strong> <em><strong>self.pretrained._modules</strong></em> and discard the layers after the layer we want to take the output from. Then, build a new Sequential (<em><strong>nn.Sequential</strong></em>) model using the remaining <em><strong>modules.</strong></em> Finally, we assign <em><strong>None</strong></em> to <em><strong>self.pretrained</strong></em> to discard the original pre-trained model and free up space (although I hope there would be a more technical or PyTorch-ic way to do it). Finally, we build the <em><strong>forward</strong></em> method.</p>
<pre><code class="hljs language-text">model = new_model(output_layer = 'layer4')
model = model.to(‘cuda:0’)
</code></pre>

<p>Another alternative way</p>
</blockquote>
<p>Here, we iterate over the <em><strong>children</strong></em> (<em><strong>self.pretrained.children()</strong></em> or <em><strong>self.pretrained.named_children()</strong></em>) of the pre-trained model and add then until we get to the layer we want to take the output from. Then, build a new Sequential (<em><strong>nn.Sequential</strong></em>) model using the children submodules. And finally, we assign <em><strong>None</strong></em> to <em><strong>self.pretrained</strong></em> as we will not be using that anymore. However, in case we do need it for anything we can always do that before freeing up the occupied space.</p>
