<p>Here we are again with the fourth article in the “<strong>Feature Extraction</strong>” series. This article will describe another method (<strong>and possibly the best method</strong>) to extract features from an intermediate layer of a model in PyTorch. We have seen some methods in two of our previous articles (links are given below) which were quite different from this approach. These two methods do not use forward hooks but are based on inheriting the respective model classes and overriding some attributes and the forward function to obtain output from the desired layer. But these methods fail if we want to obtain the predictions also along with the output of an intermediate layer.</p>

<p>To avoid the issues associated with the above methods, it is better to use forward hooks to obtain output from intermediate layers. We can also use this (these) output(s) for calculating loss (and subsequently the gradients) with respect to the target output.</p>
<hr>
<p>Hooks are functions which we can register on a Module or a Tensor. Hooks are of two types: <strong>forward</strong> and <strong>backward</strong>. These hooks are mainly triggered by <strong>forward</strong> or <strong>backward</strong> pass.</p>
<p>For the forward hook, the function is of the form</p>
<pre><code class="hljs language-text">hook(module, input, output) -> None or modified output
</code></pre>
<p><em><strong>input</strong></em> is the input to the <em><strong>module</strong></em> and <em><strong>output</strong></em> is the output obtained after the input is passed through the <em><strong>module</strong></em>.</p>
<p>For the backward hook, the function is of the form</p>
<pre><code class="hljs language-text">hook(module, grad_input, grad_output) -> Tensor or None
</code></pre>
<p><em><strong>grad_input</strong></em> is the gradient of the <strong>input</strong> to the <em><strong>module</strong></em> and <em><strong>grad_output</strong></em> is the gradient of the <strong>output</strong> of the <strong>module</strong> with respect to the Loss. <em><strong>It does not give the gradients of the parameters with respect to the loss.</strong></em></p>
<p>The <em><strong>forward</strong></em> hook is triggered every time after the method <strong>forward</strong> (of the <em>Pytorch AutoGrad Function</em> <strong>grad_fn</strong>) has computed an output. We can modify the output by returning the modified output from the hook. We can also modify the input in-place but it will not have an effect on the output as this hook is triggered after the computations in the <strong>forward</strong> (of the <em>Pytorch AutoGrad Function</em> <strong>grad_fn</strong>) method are complete.</p>
<p>The <em><strong>backward</strong></em> hook will be called every time the gradients with respect to module inputs are computed (whenever <strong>backward( )</strong> of <em>Pytorch AutoGrad Function</em> <strong>grad_fn</strong> is called). <em><strong>grad_input</strong></em> and <em><strong>grad_output</strong></em> may be tuples if the module has multiple inputs or outputs. The hook should not modify its arguments, but it can optionally return a new gradient with respect to input that will be used in place of <em><strong>grad_input</strong></em> in subsequent computations.</p>
<p>There is also another type of hook <em><strong>forward_pre_hook</strong></em> which is triggered before every time the <em><strong>forward</strong></em> method is invoked. The signature for the <em><strong>forward_pre_hook</strong></em> is of the form</p>
<pre><code class="hljs language-text">hook(module, input) -> None or modified input
</code></pre>
<p>Using the <em><strong>forward_pre_hook</strong></em> the user can modify the input but returning the modified input value as a tuple or just a single modified value in the hook.</p>
<hr>
<p>For a more detailed discussion on the PyTorch AutoGrad Function and automatic differentiation, readers can refer to this <a href="https://blog.paperspace.com/pytorch-101-understanding-graphs-and-automatic-differentiation/">article</a>.</p>

<h3 id="model-withhooks"><a class="heading-anchor" aria-hidden tabindex="-1" href="#model-withhooks"><span class="anchor-icon">#</span></a>Model with hooks</h3>
<p>We create an instance of the model like this</p>
<pre><code class="hljs language-text">model = NewModel(output_layers = [7,8]).to('cuda:0')
</code></pre>
<p>We store the output of the layers in an <strong>OrderedDict</strong> and the forward hooks in a list <em><strong>self.fhooks.</strong></em> We enumerate over the layers in the pre-trained model and if the index of the layer matches with the numbers we passed as argument to the model, then a <em><strong>forward hook</strong></em> is registered and the handle is appended to the list <em><strong>self.fhooks</strong></em>. The handles can later be used for removing the hooks from the model. The hook simply creates key-value pair in the <strong>OrderedDict</strong> <em><strong>self.selected_out,</strong></em> where the output of the layers is stored with a key corresponding to the name of the layer. However, instead of the layer names, the index of the layer can also be used as keys.</p>
<p>The output obtained from the intermediate layers can also be used to calculate loss (provided there is a target/ground truth for that) and we can also back-propagate the gradients just by using</p>
<pre><code class="hljs language-text">loss.backward()
</code></pre>
<h3 id="example"><a class="heading-anchor" aria-hidden tabindex="-1" href="#example"><span class="anchor-icon">#</span></a>Example</h3>
<blockquote>
<p>Let, us create a random array with the same dimensions as ‘layer4’ (7th layer).</p>
</blockquote>
<pre><code class="hljs language-text">target_ft = torch.rand((2048,7,7), device = ‘cuda:0’)
</code></pre>
<blockquote>
<p>Let, us take an input (any random natural image will do)</p>
</blockquote>
<pre><code class="hljs language-text">x = imageio.imread(‘image_path’)
x = (x-128.0)/128.0
x = resize(x,(224,224),preserve_range = True)
x = np.repeat(np.expand_dims(x,0),8,0)
x = torch.movedim(torch.Tensor(x),3,1)
</code></pre>
<blockquote>
<p>Output</p>
</blockquote>
<pre><code class="hljs language-text">out, layerout = model(x.to(‘cuda:0’))
</code></pre>
<p>Now, <strong>layerout</strong> is an <strong>OrderedDict</strong>. We need to get the output from <em><strong>layer4</strong></em> from it. We can easily do that since the layer name is the key</p>
<pre><code class="hljs language-text">layer4out = layerout[‘layer4’]
</code></pre>
<p>Let us create a <strong>dummy loss function</strong> first. Suppose, the <strong>loss</strong> is like this</p>
<pre><code class="hljs language-text">loss = torch.sum((label-out)**2) + torch.sum(layer4out-target_ft)
</code></pre>
<blockquote>
<p>Last step</p>
</blockquote>
<pre><code class="hljs language-text">loss.backward()
</code></pre>
