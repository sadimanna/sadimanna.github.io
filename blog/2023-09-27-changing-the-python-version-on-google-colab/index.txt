<p><img src="/images/blog/changing-the-python-version-on-google-colab/img1.jpeg" alt=""></p>
<p>If you log in to Colab (as of the date of writing this article), the Python version we get is 3.10. However, we may require a different version of Python to reproduce the results of a paper because of the dependency of a library. Let’s see how we can do that in some simple steps.</p>
<h2 id="step-1-update-apt-packages"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-1-update-apt-packages"><span class="anchor-icon">#</span></a>Step 1: Update Apt Packages</h2>
<pre><code class="hljs language-text">!apt-get update -y
</code></pre>
<h2 id="step-2-install-python-version"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-2-install-python-version"><span class="anchor-icon">#</span></a>Step 2: Install Python Version</h2>
<p>Suppose we want to install Python-3.8</p>
<pre><code class="hljs language-text">!apt-get install python3.8 python3.8-distutils
</code></pre>
<h2 id="step-3-configure-update-alternatives"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-3-configure-update-alternatives"><span class="anchor-icon">#</span></a>Step 3: Configure Update-Alternatives</h2>
<pre><code class="hljs language-text">!update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.8 1
</code></pre>
<h2 id="step-4-verify-python-version"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-4-verify-python-version"><span class="anchor-icon">#</span></a>Step 4: Verify Python Version</h2>
<pre><code class="hljs language-text">!update-alternatives --config python3
</code></pre>
<h2 id="step-5-install-and-upgrade-pip"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-5-install-and-upgrade-pip"><span class="anchor-icon">#</span></a>Step 5: Install and Upgrade Pip</h2>
<pre><code class="hljs language-text">!apt-get install python3-pip
!python3 -m pip install --upgrade pip --user
</code></pre>
<p>Now you are good to go!</p>
<hr>
<p>If we don't install <strong>python3.8-distutils</strong>, then we will get the error shown below when upgrading <em><strong>pip.</strong></em></p>
<pre><code class="hljs language-text">ModuleNotFoundError: No module named ‘distutils.cmd’
</code></pre>
