<p><img src="/images/blog/profiling-different-algorithms-using-the-built-in-timeit-mod/img1.jpeg" alt=""></p>
<p>As a developer or data scientist, understanding the performance of your algorithms is crucial. Python’s <em>timeit</em> module is a powerful tool for measuring execution time, allowing you to compare different implementations and make informed decisions about which algorithm to use. In this blog post, we’ll explore how to use <em>timeit</em> to profile different algorithms, using sorting methods and random sampling as examples.</p>
<ol>
<li>Introduction to <em><strong>timeit</strong></em></li>
</ol>
<p>The <em><strong>timeit</strong></em> module provides a simple way to time small bits of Python code. It runs a statement multiple times and provides the total execution time. This approach helps to average out any small fluctuations in execution time due to system load or other factors.</p>
<ol>
<li>Basic Usage of <em><strong>timeit</strong></em></li>
</ol>
<p>Here’s a simple example of how to use <em><strong>timeit</strong></em>:</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> timeit  
<span class="hljs-comment"># Code to be timed </span>
code_to_test = <span class="hljs-string">''' 
sum([i2 for i in range(1000)]) 
'''</span>  
<span class="hljs-comment"># Run the code 10000 times and measure the total time </span>
execution_time = timeit.timeit(code_to_test, number=<span class="hljs-number">10000</span>)  
<span class="hljs-built_in">print</span>(<span class="hljs-string">f"Execution time: <span class="hljs-subst">{execution_time:<span class="hljs-number">.6</span>f}</span> seconds"</span>)
</code></pre>
<p>To see how we can use <em><strong>timeit</strong></em>, let us go through some examples.</p>
<blockquote>
<p>Profiling Sorting Algorithms</p>
</blockquote>
<p>Let’s compare three sorting algorithms: bubble sort, quick sort, and Python’s built-in sort. We’ll use <em><strong>timeit</strong></em> to measure their performance:</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> timeit 
<span class="hljs-keyword">import</span> random  
<span class="hljs-comment"># Define the algorithms </span>
<span class="hljs-keyword">def</span> <span class="hljs-title function_">bubble_sort</span>(<span class="hljs-params">arr</span>):     
    n = <span class="hljs-built_in">len</span>(arr)     
    <span class="hljs-keyword">for</span> i <span class="hljs-keyword">in</span> <span class="hljs-built_in">range</span>(n):         
        <span class="hljs-keyword">for</span> j <span class="hljs-keyword">in</span> <span class="hljs-built_in">range</span>(<span class="hljs-number">0</span>, n-i-<span class="hljs-number">1</span>):             
            <span class="hljs-keyword">if</span> arr[j] > arr[j+<span class="hljs-number">1</span>]:                 
                arr[j], arr[j+<span class="hljs-number">1</span>] = arr[j+<span class="hljs-number">1</span>], arr[j]     
    <span class="hljs-keyword">return</span> arr  

<span class="hljs-keyword">def</span> <span class="hljs-title function_">quick_sort</span>(<span class="hljs-params">arr</span>):     
    <span class="hljs-keyword">if</span> <span class="hljs-built_in">len</span>(arr) &#x3C;= <span class="hljs-number">1</span>:         
        <span class="hljs-keyword">return</span> arr     
    pivot = arr[<span class="hljs-built_in">len</span>(arr) // <span class="hljs-number">2</span>]     
    left = [x <span class="hljs-keyword">for</span> x <span class="hljs-keyword">in</span> arr <span class="hljs-keyword">if</span> x &#x3C; pivot]     
    middle = [x <span class="hljs-keyword">for</span> x <span class="hljs-keyword">in</span> arr <span class="hljs-keyword">if</span> x == pivot]     
    right = [x <span class="hljs-keyword">for</span> x <span class="hljs-keyword">in</span> arr <span class="hljs-keyword">if</span> x > pivot]     
    <span class="hljs-keyword">return</span> quick_sort(left) + middle + quick_sort(right)  

<span class="hljs-keyword">def</span> <span class="hljs-title function_">python_sort</span>(<span class="hljs-params">arr</span>):     
    <span class="hljs-keyword">return</span> <span class="hljs-built_in">sorted</span>(arr)  

<span class="hljs-comment"># Setup: create a list of random numbers </span>
setup_code = <span class="hljs-string">''' 
    import random arr = [random.randint(1, 1000) for _ in range(1000)] 
    '''</span>  

<span class="hljs-comment"># Define the code to be timed for each algorithm </span>
bubble_sort_code = <span class="hljs-string">'bubble_sort(arr.copy())'</span> 
quick_sort_code = <span class="hljs-string">'quick_sort(arr.copy())'</span> 
python_sort_code = <span class="hljs-string">'python_sort(arr.copy())'</span>  

<span class="hljs-comment"># Run the timing tests </span>
number = <span class="hljs-number">100</span>  

<span class="hljs-comment"># number of times to run each test  </span>
bubble_time = timeit.timeit(bubble_sort_code, setup=setup_code, <span class="hljs-built_in">globals</span>=<span class="hljs-built_in">globals</span>(), number=number) 
quick_time = timeit.timeit(quick_sort_code, setup=setup_code, <span class="hljs-built_in">globals</span>=<span class="hljs-built_in">globals</span>(), number=number) 
python_time = timeit.timeit(python_sort_code, setup=setup_code, <span class="hljs-built_in">globals</span>=<span class="hljs-built_in">globals</span>(), number=number)  

<span class="hljs-comment"># Print results </span>
<span class="hljs-built_in">print</span>(<span class="hljs-string">f"Bubble Sort time: <span class="hljs-subst">{bubble_time:<span class="hljs-number">.6</span>f}</span> seconds"</span>) 
<span class="hljs-built_in">print</span>(<span class="hljs-string">f"Quick Sort time: <span class="hljs-subst">{quick_time:<span class="hljs-number">.6</span>f}</span> seconds"</span>) 
<span class="hljs-built_in">print</span>(<span class="hljs-string">f"Python's built-in sort time: <span class="hljs-subst">{python_time:<span class="hljs-number">.6</span>f}</span> seconds"</span>)
</code></pre>

<blockquote>
<p>Tips for Effective Profiling</p>
</blockquote>
<ul>
<li>Use the ‘<strong>setup</strong>’ parameter in <em><strong>timeit.timeit</strong></em>() to prepare any necessary data or imports.</li>
<li>Use the ‘<strong>globals</strong>’ parameter if your functions are defined in the global scope.</li>
<li>Adjust the ‘<strong>number</strong>’ parameter based on how long your algorithms take to run.</li>
<li>Run your tests multiple times and average the results for more reliable measurements.</li>
<li>Be aware of factors that can affect timing, such as system load and Python’s garbage collection.</li>
</ul>
<blockquote>
<p>Interpreting the Results</p>
</blockquote>
<p>When interpreting the results, remember that the fastest algorithm isn’t always the best choice. Consider other factors such as:</p>
<ul>
<li><em>Space complexity</em></li>
<li><em>Code readability and maintainability</em></li>
<li><em>Specific use cases and data characteristics</em></li>
<li><em>Scalability for larger datasets</em></li>
</ul>
<blockquote>
<p>Conclusion</p>
</blockquote>
<p>Profiling your algorithms with <em><strong>timeit</strong></em> is a valuable skill for any Python developer. It allows you to make data-driven decisions about which algorithms to use in your projects. Remember, while timing is important, it’s just one aspect of algorithm selection. Always consider the broader context of your project when choosing between different implementations.</p>
<p>By mastering the use of <em><strong>timeit</strong></em>, you’ll be better equipped to optimize your code and create more efficient Python programs. Happy profiling!</p>
