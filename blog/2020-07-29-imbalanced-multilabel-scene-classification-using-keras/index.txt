<p><em><strong>Imbalanced</strong></em> classfication refers to the classification tasks in which the distribution of samples among the different classes are unequal. Generally, in an imbalanced classification task, the degree of imbalance can range from slight imbalance to severe imbalance, like in cases where there are only 1 example in a class. This type of tasks are very challenging and often the minority class is the more important class. Most of the classification algorithms are based on dataset which have almost balanced data distribution for all the classes. Hence, these conventional algorithms perform very badly on imbalanced datasets.</p>
<p><em><strong>Multilabel</strong></em> classification is different from <em><strong>Multiclass</strong></em> classification. In multiclas classification, each sample belongs to only one of the many classes. But in <em><strong>Multilabel</strong></em> classification, a single sample may belong to more than one class.</p>
<hr>
<p>The data set that we are using for this project is the <em><strong>Multi-instance Multi-Label Learning</strong></em> dataset, available <a href="http://www.lamda.nju.edu.cn/data_MIMLimage.ashx">here</a>.</p>
<p>This package contains two parts:</p>
<ul>
<li>The “<strong>original</strong>” part contains 2000 natural scene images.</li>
<li>The “<strong>processed</strong>” part contains data sets for multi-instance multi-label learning.</li>
</ul>
<p>The image data set consists of 2,000 natural scene images, where a set of labels is assigned to each image. The number of images belonging to more than one class (e.g. <em>sea+sunset</em>) comprises over 22% of the data set, many combined classes (e.g. <em>mountains+sunset +trees</em>) are extremely rare. On average, each image is associated with 1.24 class labels. Overall, there are 5 distinct labels, <em><strong>desert</strong></em>, <em><strong>mountains</strong></em>, <em><strong>sea</strong></em>, <em><strong>sunset</strong></em>, <em><strong>trees</strong></em>.</p>
<p>The “<strong>processed</strong>” part of this package contains the multi-instance multi-label data (in MATLAB format) obtained from the natural scene images. This file can be read using <code>scipy.io.loadmat</code> and then converted into a dataframe for ease of use. The <code>target</code> column contains the labels and the <code>class_names</code> field contains the class names.</p>
<p>Now, let us try our hands on the task. In this post we will be using Keras. However, most of the part, like processing the data and making the Data Generator (Data Loader in PyTorch) will be similar when using PyTorch. Only the code for the building the model and training will be different. Rest of the part is just simple python!</p>
