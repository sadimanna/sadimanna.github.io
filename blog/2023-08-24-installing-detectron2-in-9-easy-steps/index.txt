<p>When installing detectron2, we often face an error saying that there is a <em><strong>mismatch between the CUDA version with which PyTorch (say, 11.7) was compiled and the CUDA version available in the system (say, 12.1)</strong></em>.</p>
<p><em><strong>A possible solution</strong></em> is to use a <strong>Docker</strong> container</p>
<hr>
<p>In this article, we will go through the steps to set up a <strong>Docker</strong> container inside the <strong>Windows Subsystem for Linux (WSL2)</strong> on <strong>Windows 11</strong>.</p>
<h2 id="step-by-step-installation"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-by-step-installation"><span class="anchor-icon">#</span></a>Step-by-Step Installation</h2>
<h3 id="step-1-install-wsl2-on-windows"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-1-install-wsl2-on-windows"><span class="anchor-icon">#</span></a>Step 1: Install WSL2 on Windows</h3>
<p>Install <strong>WSL2</strong> on <strong>Windows</strong>Follow the steps given<a href="https://learn.microsoft.com/en-us/windows/wsl/install"><strong>here</strong></a><strong>.</strong></p>
<h3 id="step-2-install-docker-desktop"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-2-install-docker-desktop"><span class="anchor-icon">#</span></a>Step 2: Install Docker Desktop</h3>
<p>Install <strong>Docker Desktop</strong> on <strong>Windows</strong>Follow the steps given<a href="https://docs.docker.com/desktop/install/windows-install/"><strong>here</strong></a><strong>.</strong></p>
<h3 id="step-3-pull-cuda-docker-image"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-3-pull-cuda-docker-image"><span class="anchor-icon">#</span></a>Step 3: Pull CUDA Docker Image</h3>
<pre><code class="hljs language-bash">docker pull nvcr.io/nvidia/cuda:11.7.0-base-ubuntu22.04
</code></pre>
<h3 id="step-4-run-the-docker-container"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-4-run-the-docker-container"><span class="anchor-icon">#</span></a>Step 4: Run the Docker Container</h3>
<pre><code class="hljs language-bash">docker run -it --gpus all nvcr.io/nvidia/cuda:11.7.0-base-ubuntu22.04
</code></pre>
<h3 id="step-5-update-and-upgrade-packages"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-5-update-and-upgrade-packages"><span class="anchor-icon">#</span></a>Step 5: Update and Upgrade Packages</h3>
<pre><code class="hljs language-text">apt-get update &#x26;&#x26; apt-get upgrade
</code></pre>
<h3 id="step-6-install-python-3x"><a class="heading-anchor" aria-hidden tabindex="-1" href="#step-6-install-python-3x"><span class="anchor-icon">#</span></a>Step 6: Install Python 3.x</h3>
<pre><code class="hljs language-bash">apt install python3
</code></pre>
<blockquote>
<p>Seventh: Install pip because you will need it</p>
</blockquote>
<pre><code class="hljs language-bash">apt install python3-pip
</code></pre>
<blockquote>
<p>Eight: Install the required libraries</p>
</blockquote>
<p>For <em><strong>opencv</strong></em> dependencies, run the following command first:</p>
<pre><code class="hljs language-text">apt-get install ffmpeg libsm6 libxext6
</code></pre>
<p>otherwise, when importing <em><strong>detectron2,</strong></em> an <strong>ImportError</strong> like</p>
<pre><code class="hljs language-text">ImportError: libGL.so.1: cannot open shared object file: No such file or directory
</code></pre>
<p>will occur. If you install <em><strong>libgl1</strong></em> after seeing this error, you will get</p>
<pre><code class="hljs language-text">ImportError: libgthread-2.0.so.0: cannot open shared object file: No such file or directory
</code></pre>
<p>when you try to import <em><strong>detectron2</strong></em> again. I did not face any issues when installing <em><strong>opencv</strong></em>, but when importing <em><strong>detectron2</strong></em> later, the above errors occurred.</p>
<p>To install the required libraries, run</p>
<pre><code class="hljs language-text">python3 -m pip install numpy matplotlib scikit-learn scikit-image opencv-python opencv-contrib-python …
</code></pre>
<p>To install PyTorch, run</p>
<pre><code class="hljs language-text">python3 -m pip install torch==1.13.1+cu117 torchvision==0.14.1+cu117 torchaudio==0.13.1 --extra-index-url https://download.pytorch.org/whl/cu117
</code></pre>
<blockquote>
<p>Ninth: Install detectron2</p>
</blockquote>
<p>First, install <em><strong>git</strong></em></p>
<pre><code class="hljs language-bash">apt install git
</code></pre>
<p>Then install detectron2</p>
<pre><code class="hljs language-text">python3 -m pip install 'git+https://github.com/facebookresearch/detectron2.git'
</code></pre>
<blockquote>
<p>Save this Container as an Image</p>
</blockquote>
<p>Run</p>
<pre><code class="hljs language-bash">docker ps
</code></pre>
<p>to check the container ID. To commit the changes to the container, run</p>
<pre><code class="hljs language-bash">docker commit [CONTAINED ID] [REPOSITORY[:TAG]]
</code></pre>
<p>In my case, the command was</p>
<pre><code class="hljs language-bash">docker commit 870b62170e7e detectron2_cuda11.7.0-ubuntu22.04
</code></pre>
<blockquote>
<p>Check the newly created Image by running</p>
</blockquote>
<pre><code class="hljs language-bash">docker images
</code></pre>
<blockquote>
<p>Stop the running container and start the new image</p>
</blockquote>
<pre><code class="hljs language-bash">docker run -it --gpus all detectron2_cuda11.7.0-ubuntu22.04
</code></pre>
<p>There you go! Now the installed libraries won’t vanish every time you remove the container and can be used on other systems as well!</p>
<p><strong>Additional Features</strong>:</p>
<blockquote>
<p>NVIDIA Driver</p>
</blockquote>
<p>Using</p>
<pre><code class="hljs language-text">--gpus=all
</code></pre>
<p>is essential; otherwise, the following error will occur:</p>
<pre><code class="hljs language-text">AssertionError: Found no NVIDIA driver on your system. 
Please check that you have an NVIDIA GPU and 
installed a driver from http://www.nvidia.com/Download/index.aspx
</code></pre>
<blockquote>
<p>To access a directory on the host system from within the docker container use <strong>bind mounts</strong></p>
</blockquote>
<pre><code class="hljs language-bash">docker run -it --gpus all --mount <span class="hljs-built_in">type</span>=<span class="hljs-built_in">bind</span>,src=/path/to/directory,target=/path detectron2_cuda11.7.0-ubuntu22.04
</code></pre>
<p>Now, you can access all the files in the source directory on the host system.</p>
<blockquote>
<p>To enable the <em><strong>nvidia-smi</strong></em> tool in the container, enable the <em><strong>utility</strong></em> driver capability</p>
</blockquote>
<pre><code class="hljs language-bash">docker run -it --gpus <span class="hljs-string">'all,capabilities=compute,utility'</span> --mount <span class="hljs-built_in">type</span>=<span class="hljs-built_in">bind</span>,src=/path/to/directory,target=/path detectron2_cuda11.7.0-ubuntu22.04
</code></pre>
