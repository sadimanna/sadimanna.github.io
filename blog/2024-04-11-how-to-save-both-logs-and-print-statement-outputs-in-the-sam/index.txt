<p>Logs and Python</p>
<hr>
<blockquote>
<p>While doing one experiment, I needed to save the logs and the print statement outputs, in the same log file. Both the logs and print statement outputs were being printed in the terminal, and no file was being saved. While it is fairly easy to use the Python <a href="https://docs.python.org/3/library/logging.html">logging</a> library to instantiate a StreamHandler or FileHandler with the logger, redirecting the print statement outputs to the same file was not easy, and requires expertise I didn’t have. After searching the web for a while, I came across two resources, one on the blog <a href="https://www.electricmonk.nl/log/2011/08/14/redirect-stdout-and-stderr-to-a-logger-in-python/">Electric Monk</a>, and another on <a href="https://stackoverflow.com/questions/11124093/redirect-python-print-output-to-logger">StackOverflow</a>. While I later found out, that there are other resources of a similar nature, but combining these two seemed to work for me. Hence, in this article, I am going to present the piece that worked for me.</p>
</blockquote>
<hr>
<p>First, we will define a wrapper for the Python logger, named <em><strong>StreamToLogger</strong></em>.</p>
<pre><code class="hljs language-python"><span class="hljs-keyword">import</span> logging
<span class="hljs-keyword">import</span> sys


<span class="hljs-keyword">class</span> <span class="hljs-title class_">StreamToLogger</span>(<span class="hljs-title class_ inherited__">object</span>):
    <span class="hljs-string">"""
    Fake file-like stream object that redirects writes to a logger instance.
    """</span>
    <span class="hljs-keyword">def</span> <span class="hljs-title function_">__init__</span>(<span class="hljs-params">self, logger, log_level=logging.INFO</span>):
        <span class="hljs-variable language_">self</span>.logger = logger
        <span class="hljs-variable language_">self</span>.log_level = log_level
        <span class="hljs-variable language_">self</span>.linebuf = <span class="hljs-string">''</span>

    <span class="hljs-keyword">def</span> <span class="hljs-title function_">write</span>(<span class="hljs-params">self, buf</span>):
        temp_linebuf = <span class="hljs-variable language_">self</span>.linebuf + buf
        <span class="hljs-variable language_">self</span>.linebuf = <span class="hljs-string">''</span>
        <span class="hljs-keyword">for</span> line <span class="hljs-keyword">in</span> temp_linebuf.splitlines(<span class="hljs-literal">True</span>):
            <span class="hljs-keyword">if</span> line[-<span class="hljs-number">1</span>] == <span class="hljs-string">'\n'</span>:
                <span class="hljs-variable language_">self</span>.logger.log(<span class="hljs-variable language_">self</span>.log_level, line.rstrip())
            <span class="hljs-keyword">else</span>:
                <span class="hljs-variable language_">self</span>.linebuf += line

    <span class="hljs-keyword">def</span> <span class="hljs-title function_">flush</span>(<span class="hljs-params">self</span>):
        <span class="hljs-keyword">if</span> <span class="hljs-variable language_">self</span>.linebuf != <span class="hljs-string">''</span>:
            <span class="hljs-variable language_">self</span>.logger.log(<span class="hljs-variable language_">self</span>.log_level, <span class="hljs-variable language_">self</span>.linebuf.rstrip())
        <span class="hljs-variable language_">self</span>.linebuf = <span class="hljs-string">''</span>
</code></pre>
<p>Then, we are going to instantiate a logger and set up the basic configurations we would like the logs to be in.</p>
<h4 id="logger-instantiation"><a class="heading-anchor" aria-hidden tabindex="-1" href="#logger-instantiation"><span class="anchor-icon">#</span></a><strong>Logger Instantiation</strong></h4>
<pre><code class="hljs language-text">logger = logging.getLogger('logs')
</code></pre>
<h4 id="instantiate-filehandler"><a class="heading-anchor" aria-hidden tabindex="-1" href="#instantiate-filehandler"><span class="anchor-icon">#</span></a>Instantiate FileHandler</h4>
<pre><code class="hljs language-text">logger.handlers = []
fh = logging.FileHandler(filename=f’{BASE_PATH}/out.log’, mode = ‘a’)
formatter = logging.Formatter(‘[%(levelname).1s] %(name)s >> “%(message)s”’)
fh.setFormatter(formatter)
logger.addHandler(fh)
logger.setLevel("WARNING")
</code></pre>
<p>For redirecting the <em><strong>print</strong></em> statement outputs to the <em><strong>log</strong></em> file, we are going to wrap the logger in the <em><strong>StreamToLogger</strong></em> object</p>
<pre><code class="hljs language-text">wrapped_logger = StreamToLogger(logger, logging.INFO)
</code></pre>
<p>Finally, we need to set STDOUT to the wrapped logger</p>
<pre><code class="hljs language-text">sys.stdout = wrapped_logger
</code></pre>
<p>Now, we can save both logs and print statement outputs to a single file.</p>
<pre><code class="hljs language-python">logger.info(<span class="hljs-string">"Logger instantiated"</span>)
<span class="hljs-built_in">print</span>(<span class="hljs-string">"Print statement logging to file"</span>)
</code></pre>
<p>We can test if it works by printing the lines that have been appended to the text file. However, we first need to restore the functionality of <em><strong>sys.stdout</strong></em>.</p>
<pre><code class="hljs language-python">sys.stdout = sys.__stdout__
<span class="hljs-keyword">with</span> <span class="hljs-built_in">open</span>(‘./log2.txt’) <span class="hljs-keyword">as</span> f:
  l = f.readlines()
  <span class="hljs-keyword">for</span> line <span class="hljs-keyword">in</span> l:
    <span class="hljs-built_in">print</span>(line)
</code></pre>
<p><em><strong>sys.__stdout__</strong></em> stores the original values of <em><strong>sys.stdout</strong></em>.</p>
<p>For <strong>IPython</strong> kernels, however, we need to run</p>
<pre><code class="hljs language-text">oldstdout = sys.stdout
</code></pre>
<p>before assigning the <em><strong>wrapped_logger</strong></em> to <em><strong>sys.stdout</strong></em>. And then restore it before executing any print statements.</p>
<pre><code class="hljs language-python">sys.stdout = oldstdout
<span class="hljs-keyword">with</span> <span class="hljs-built_in">open</span>(<span class="hljs-string">'./log2.txt'</span>) <span class="hljs-keyword">as</span> f:
  l = f.readlines()
  <span class="hljs-keyword">for</span> line <span class="hljs-keyword">in</span> l:
  <span class="hljs-built_in">print</span>(line)
</code></pre>
<p>The output should look like this</p>
<pre><code class="hljs language-text">[I] logs >> “Logger instantiated” 
[I] logs >> “Print statement logging to file”
</code></pre>
<blockquote>
<p>A note from the StackOverflow answer:</p>
</blockquote>
<p>From the io.TextIOWrapper docs: On output, if a newline is <strong>None</strong>, any '<strong>\n</strong>' characters written are translated to the system default line separator. By default <em><strong>sys.stdout.write()</strong></em> expects '<strong>\n</strong>' newlines and then translates them, so this is still cross-platform.</p>
