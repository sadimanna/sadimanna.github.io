1. SimCLR depends heavily on data augmentation.

3. Check the linear evaluation hyper-parameters. The performance depends on the learning rate and batch size.

4. If your data is multi-label then you need to consider other techniques, e.g. https://arxiv.org/abs/2308.03286

Linear evaluation will not work well in case of multi-label data. In case, you want to do only linear evaluation, you may want to change you prediction layer to output multilabel probabilities as more than one class may be present in a sample.

These are some things you can look into.

Any other SSL methods like MoCov2 may also help with the batch size issue as it uses a memory bank. Methods like BYOL, VICReg, Barlow Twins will also work but you need to be careful about the batch size.

Before proceeding further, you can plot the embeddings from the last layer of the encoder using tSNE to visually inspect if the representations that the encoder learnt are not collapsed.
