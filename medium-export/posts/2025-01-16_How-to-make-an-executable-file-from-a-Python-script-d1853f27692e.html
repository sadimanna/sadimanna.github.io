How to make an executable file from a Python script

To create a binary executable from Python script, you’ll need to use a tool that can package your Python code into a standalone executable.

Here are a few popular options:

1. PyInstaller

PyInstaller is a popular tool for converting Python scripts into standalone executables. Here’s a basic example of how to use PyInstaller:

Installation

pip install pyinstaller

Usage
Navigate to your project directory and run:

pyinstaller --onefile dummyce.py

This will create a standalone executable in a `dist` directory.

2. cx_Freeze

cx_Freeze is another tool for freezing Python scripts into executables. Here’s a basic example:

Installation

pip install cx_Freeze

Usage
Create a `setup.py` file with the following content:

from cx_Freeze import setup, Executable
setup(
 name=”Your Chess Engine”,
 version=”1.0",
 description=”Your chess engine description”,
 executables=[Executable(“dummyce.py”)]
)

Then, run:

python setup.py build

This will create a standalone executable in a `build` directory.

3. Py2Exe

Py2Exe is a tool for converting Python scripts into Windows executables. Here’s a basic example:

Installation

pip install py2exe

Usage
Create a `setup.py` file with the following content:

from distutils.core import setup
import py2exe

setup(
 console=[‘dummyce.py’]
)

Then, run:

python setup.py py2exe

This will create a standalone executable in a `dist` directory.

The reader is free to choose any tool. However, it should be noted that while pyinstaller is supported on Windows, Linux and MacOS, and cx_Freeze also creates cross-platform executables, py2exe works only on Windows.
