**Tutorial: Build a Weather Web App with Flask and WeatherAPI**

**Introduction**

In this tutorial, we’ll build a simple weather web application using Flask, a popular Python web framework, and WeatherAPI, a free weather data API. This app will allow users to enter a city name and retrieve the current weather conditions.

**Step 1: Set up Flask**

1. Install Flask using pip: `pip install flask`
2. Import Flask in your Python file: `from flask import Flask, render_template, request`
3. Create a Flask app instance: `app = Flask(__name__)`
4. Define a route for the root URL: `@app.route(“/”, methods=[“GET”, “POST”])`

 
**Step 2: Create the Weather App HTML Template (continued)**
3. Add a form to input city name:
```
<form action=”/” method=”post”>
 City: <input type=”text” id=”city” name=”city” required><br><br>
 <button>Get Weather</button>
</form>
```
4. Add placeholders for weather data:
```
<p>Weather in {{ city }}:</p>
<p>Temperature: {{ temp }}°C</p>
<p>Condition: {{ condition }}</p>
```
**Step 3: Integrate WeatherAPI with Flask**
1. Import requests library: `import requests`
2. Get API key from WeatherAPI
3. Define API endpoint URL: `base_url = f”http://api.weatherapi.com/v1/current.json?key={api_key}&q={city}"`
4. Make GET request to API: `response = requests.get(base_url)`
5. Parse JSON response: `weather_data = response.json()`
**Full Flask Code:**
```
from flask import Flask, render_template, request
import requests
app = Flask(__name__)
@app.route(“/”, methods=[“GET”, “POST”])
def index():
 if request.method == “POST”:
 city = request.form[“city”]
 api_key = “YOUR_API_KEY”
 base_url = f”http://api.weatherapi.com/v1/current.json?key={api_key}&q={city}"
 response = requests.get(base_url)
 weather_data = response.json()
 temp = weather_data[‘current’][‘temp_c’]
 condition = weather_data[‘current’][‘condition’][‘text’]
 return render_template(“weather.html”, city=city, temp=temp, condition=condition)
 else:
 return render_template(“weather.html”)
if __name__ == “__main__”:
 app.run()
```
